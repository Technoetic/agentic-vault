# 로컬 개선판 검증 기록

2026-09-05 · `0.9.0-local.1` · upstream 기준 `74890f6`

Windows에서 Python 3.12.10, Git 2.55.0.windows.3, Claude Code 2.1.252로 검증했다.
이 기록은 실제로 실행한 로컬 검사와 아직 실행하지 않은 검사를 구분한다.

## 최종 실행 결과

| 검사 | 결과 |
|---|---|
| 전체 unittest | 288개 수집, **280개 통과, 8개 건너뜀, 실패 0개** · 57.743초 · exit 0 |
| 한국어 8개·영어 8개 질의 | recall@3 **1.0**, MRR@3 **1.0**, 두 언어 모두 동일 · exit 0 |
| Python compileall | exit 0 |
| Claude plugin·marketplace manifest 엄격 검증 | 모두 통과 · exit 0 |
| Claude commands·skills 엄격 검증 | 모두 통과 · exit 0 |
| staged·unstaged Git 공백 검사 | 모두 exit 0 |

건너뛴 8개는 Windows 심볼릭 링크 생성 권한이 필요한 6개와 POSIX FIFO 전용
2개다. Windows 정션을 사용하는 경계·복구 테스트는 실제 실행해 통과했다.

검색 fixture는 활성 노트 24개와 비공개 유인 문서 1개다. 각 질의에 어휘가
일치하는 경쟁 후보가 4~7개 있다. 전체 순위를 의도적으로 뒤집으면 recall@3와
MRR@3가 모두 0.0이 되고 evaluator가 exit 1을 반환하는 것도 확인했다.
이는 작은 고정 자료에서의 순위 회귀를 감지한다는 뜻이다.

독립 검토에서 발견한 건강 검사기의 비공개 경로 누출, 유니코드 발췌 위치,
파일 증가 시 누락 진단 문제를 수정했다. 별도 검토자가 원래 누출 사례와
유니코드 사례를 다시 실행하여 수정 여부를 확인했다.

## 회귀 테스트가 확인하는 동작

- 세션 주입 전에 config·deny zone·경로를 검사하고, 헤더와 생략 표시를 포함한
  추정 토큰 예산을 지킨다. 잘못된 설정은 노트 내용 없이 진단한다.
- 전체 건강 검사도 비공개 노트의 본문을 보고서에 노출하지 않는다. 실제
  Windows 정션으로 볼트 밖 경로를 구성한 회귀 테스트를 포함한다.
- 독립 백업을 검증한 뒤 새 폴더로 복구한다. 삭제한 미추적 바이너리와 Git
  이력 bundle의 복구를 확인한다. 기존 작업 폴더는 덮어쓰지 않는다.
- 백업 시점의 볼트를 복구한 뒤 실제 SessionStart·recall CLI를 실행해 당시의
  결정과 출처가 반환되는지 확인한다. 원본을 이후에 수정·삭제한 경우도 포함한다.
- 검색 결과의 경로·행·발췌문을 실제 파일과 대조하고, 어휘 검색의 읽기 제한과
  누락 진단을 확인한다. 한국어·영어의 고정 질의는 별도 evaluator로 측정한다.

## 해석 범위

`plugin validate --strict`는 manifest와 명령·스킬의 정적 검증이다. 실제 Claude
대화에서의 지시 수행, 모델 답변 정확도, 요약의 사실성은 측정하지 않는다.

CI는 Ubuntu/Windows/macOS와 Python 3.10/3.12/3.14의 9개 조합으로 구성했다.
원격 CI는 실행하지 않았다. 실제 모델의 규칙 상속과 Telegram 송수신도 검증하지
않았다. 테스트는 임시 파일·Git 저장소를 사용하며 외부 API를 호출하지 않는다.

파일 읽기는 신뢰할 수 있는 파일시스템을 전제로 한다. 다른 프로세스가 검증 후
경로를 악의적으로 바꾸는 상황까지 차단하는 OS 샌드박스는 제공하지 않는다.
검색 fixture 점수는 해당 어휘 검색 사례에 대한 회귀 지표이며, 의미 회상이나
개인 볼트에서의 성능을 보장하지 않는다.

재현 명령과 사용법은 [보장과 사용법](reliability.md)에 있다.
