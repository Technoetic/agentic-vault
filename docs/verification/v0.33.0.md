Observed on Windows with Python 3.12: the full suite ran 2,537 tests in
1,407.344 seconds, with 43 skips and no failures or errors. Fifteen CLI checks,
independent component, final and aggregate verification, and 56 flags-off

## Final release gates

At documentation preparation time the following gates are pending. The external
pre-publication `verification.json` records the final fixed source SHA, actual
commands, results and gate status; this document does not assert they passed.

- Final-tree full suite and focused metadata, README truth, Codex verification,
  feature and supply-chain checks; independently re-run checker fingerprint and
  certificate migration matrix in both directions against v0.32.0.
- Flags-off output comparisons on the final tree, including the existing 56
  comparisons, and explicit opt-in evaluator/support-row CLI checks.
- Claude plugin validation and disposable native Codex installation/discovery
  with installed-byte resource checks, isolated `CODEX_HOME` and zero model turns.
- Master and tag CI, including the platform/Python matrix, stateful jobs and
  evaluation jobs; advisory supply-chain status recorded separately.
- Canonical LF source export, reproducible `TZ=UTC0` ZIP, `rebuild_spec`, L1 byte
  equality and L2 Git-blob/member equality; independent final source/package review.
- GitHub immutability check, draft assets `agentic-vault-0.33.0.zip`, `SHA256SUMS`
  and `verification.json`, then authorized publication.

Final asset review, public re-download hashes, attestation, Latest/immutable state
and final refs belong in external `post-publication.json`, since immutable assets
cannot record their own later review. The packaging and publication procedure is
documented in [release integrity](../release-integrity.md).

## Limits

Scripted controls are not actual-model efficacy evidence. Exact structured slots,
declared dependencies and synthetic fixtures do not establish general language
understanding, universal evidence absence or real-vault error rates. Same-line
subject/value co-occurrence does not establish semantic attribution or truth.
Row population output is a point-in-time observation, not an atomic snapshot.
Release publication, active plugin updates and actual vault upgrades are separate
operations. No installed cache or user vault is modified by release preparation.
