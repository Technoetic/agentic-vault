## Integration

Five reviewed branches were merged into `release/v0.23.0` (from `63b4cc9`, v0.22.1) with
`--no-ff`, in this order: `feat/v023-supply-chain` (`e43a420`), `feat/v023-tool-diagnostics`
(`ec0777f`), `feat/v023-fabrication-checks` (`ca4f6ae`), `feat/v023-hangul2-bm25` (`0483afe`) and
`feat/v023-render-matched` (`5773516`). `docs/README.md` and `docs/memory-evaluation.md` merged
without conflicts; the evaluation guide's introduction was rewritten to cover both added sections. `scripts/evaluate_recall.py` and `skills/agentic-vault/scripts/vault_retrieval.py`
conflicted and were resolved by keeping both options:

- `retrieve()` takes keyword-only `lexical_ngrams` (`None` or `"hangul2"`) and `temporal_filter`
  (`"exclude"` or `"annotate_only"`). The legacy fast path runs only when every option is at its
  default, both of these included. An invalid value of either, a `str` subclass included, returns
  `invalid_options` before any note is read. Diagnostics name each option only when it is requested.
- The render-matched branch had taken the fast path for `annotate_only` with no other option. Under
  the merged rule that call returns the advanced output with the same paths and context and the
  control marker, so one render-matched test was rewritten to assert exactly that.
- `evaluate()`, `compare()` and the CLI accept both `--lexical-ngrams` and `--render-matched`. The
  render-matched arm uses the advanced arm's options plus `temporal_filter="annotate_only"`; with
  `--lexical-ngrams`, the improved, expansion-ablation and render-matched arms all use it.

No golden was regenerated. The tool-safety default output
(`tests/fixtures/tool_safety/v0.22.1-default-output.json`), the fabrication goldens
(`tests/fixtures/v0221_default_outputs.json`), the seven Hangul default-path digests and the
render-matched default-equivalence tests all pass unchanged. The merged state (`5728c2c`) ran
1,489 tests with 33 skips and zero failures or errors before the integration fixes.

## Limits

Feature evidence is synthetic. The actual local model still fails both Korean tool tasks.
Render-matched decisions are power-limited on the current fixtures and no reader model ran.
The Hangul bigram channel is not morphological analysis. Source-support checks compare literals
and have the limits listed in hardening. The supply-chain job is advisory; its zizmor 1.30.1 run
has not yet been observed in remote CI, and the pip-audit action installs pip-audit without hashes
at run time. Two existing Windows tests detect a change through a file or directory
timestamp and can miss one that lands within the same timestamp tick:
`test_previously_walked_directory_changes_make_report_partial` failed once in the `-v` run above,
and `test_vault_retrieval.AdvancedRetrievalTests.test_later_source_verification_cannot_leave_earlier_source_stale`
failed once in a focused batch run during integration. Both passed in isolated reruns (8/8 and
6/6) and in the other full runs. Neither test file changed in this release;
`vault_instruction_budget.py` is unchanged, and the hybrid default path the retrieval test uses
keeps its v0.22.1 behavior, which the Hangul default-output digests pin.
