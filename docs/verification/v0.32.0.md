## Limits

The equality of the linear-time rewrites is shown over bounded alphabets and lengths, fixed cases
and caller tests, not proven for all strings; the heading, date, header, title and dash-tail helpers
also assume no line feed in their input, and for the credential pattern only the verdict is
compared (a match may start elsewhere). The repeated-input probes find no super-linear regex left on
the default paths or in `jarvis_bridge.py`, which is not a proof; patterns built at run time were not
probed. Period known failures are counts over hand-written lexicons,
not real-vault rates, and forms outside the lexicons are not counted. Twins report one operating
point on designed fixture cases. The audit tool has not been used on a real vault. The deny-zone
guard was measured as a subprocess with the hook's command line and was not run inside a live
Claude Code session. All local runs used one Windows 11 PC with Python 3.12.10; other platforms
and Python versions are covered by CI only.
