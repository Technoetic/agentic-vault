# v0.54.0 verification contract

## Scope

Release `v0.54.0` builds on published `v0.53.2` (`fcb9a5dd368bdd74ecfa21f6e308dd3b813912f2`) and implements four Python standard-library-only security, operational, and verification improvements inspired by two upstream MIT projects (without importing Node/Rust runtimes, generic skill packs, or neuroscience pipelines):

1. **Invisible Unicode smuggling & bidi defense** (inspired by `affaan-m/ECC` `v2.2.3` `ccd8da1a72`, MIT): `hooks/session_start.py` (`_strip_invisible_smuggling`) removes `U+E0000`–`U+E007F`, `U+E0100`–`U+E01EF`, `U+202A`–`U+202E`, `U+2066`–`U+2069`, `U+180E`, `U+115F`–`U+1160`, and `U+2061`–`U+2064` before secret redaction and fake-header neutralization; `skills/agentic-vault/scripts/vault_doctor.py` applies the identical pipeline order.
2. **Read-only, no-leak hook-wiring audit & install-state ownership lifecycle** (inspired by `affaan-m/ECC` `scripts/config-health.py`, `schemas/install-state.schema.json`, and `scripts/lib/install-lifecycle.js`, MIT): `skills/agentic-vault/scripts/vault_hook_wiring.py` (`vault_doctor.py --hook-wiring`) checks static existence of referenced hook targets without printing raw commands or running hooks; `skills/agentic-vault/scripts/vault_install_state.py` (`record`, `status`, `uninstall`, and `vault_doctor.py --install-state`) records SHA-256 digests and ownership (`managed` vs `user_owned`) in `00-meta/.vault-install-state.json` and preserves user-owned or user-modified files on uninstall.
3. **Repository CI static hygiene & security tests** (inspired by `affaan-m/ECC` static CI validators, MIT): `tests/test_repo_hygiene.py` (invisible Unicode smuggling, shipped-surface personal path leaks, cross-host Claude-only skill tokens) and `tests/test_supply_chain.py` (`pull_request_target`/`workflow_run` untrusted PR checkout rejection).
4. **Provenance-bound release numbers index & declarative claim verifier** (inspired by `ai3inc/connectome-cognition-benchmark` `v1.1.0` `doi:10.5281/zenodo.24361690` `9c5d863256fdc20c341b94b874e62921e92f22c1`, MIT, specialized for `agentic-vault` release gates): `scripts/verify_release_claims.py` hashes `verification.json`, `docs/releases/vX.Y.Z.md`, and `SHA256SUMS` and enforces 10 fail-closed release invariants prior to publication.

The seven warning-promotion certificate files (`vault_lint_extensions.py`, `vault_warning_policy.py`, `vault_provenance.py`, `vault_egress.py`, `vault_ssot.py`, `jev_client.py`, `vault_paths.py`) remain byte-identical to `v0.46.0..v0.53.2` (`checker_sha256` = `09642e7aa77d0b812f5afa646b491fe2d79d44104e399bea4a3001a6f2f1279d`).

## Boundaries

- `_strip_invisible_smuggling` is Unicode hygiene, not a prompt-injection sandbox or homoglyph detector.
- `vault_hook_wiring.py` checks static file existence only and never executes hook commands.
- `vault_install_state.py` manages vault-local stamped surfaces only and never touches host global plugin caches or user-owned files.
- Live `agy` interactive sessions are not executed by automation.
