## Candidate failure and scope

The unpublished v0.39.1 candidate source
`fb92f7e79bd2c37a815df1a25b297323e20e4a1a` failed master CI run 41664026652,
job 126014409284, on Windows / Python 3.12. Its full unit job ran 2,823 tests
in 1,621.381 seconds with 18 skips and one failure: the Korean timeout test
expected one server receipt but observed zero. A 100ms deadline did not guarantee
server acceptance. This was an assertion failure rather than a CI job timeout.
No formal v0.39.1 or v0.39.0 release was published; both tags and failed CI
records remain history. The last published release remains v0.38.1 until new
publication. Candidate observations do not establish v0.39.2 results.

Stage and Korean timeout fixtures replace tiny-clock HTTP assumptions with
clock-independent deterministic bounded-call stop contracts: exactly one attempt,
no subsequent calls, both valid error codes and no successful abstention from
errors. Normal-budget actual HTTP stage and Korean 100-request contract tests
remain separate. Runtime scripts, limits, error accounting, installed defaults,
dependencies and installed-resource lists are unchanged. CI maintenance changes
only the unit-job cap from 35 to 45 minutes and its explanatory comment.

The same v0.39.1 tag run's Windows / Python 3.12 job 126014408786 failed that
assertion after 2,823 tests in 1,956.182 seconds with 18 skips and one failure.
Its unit step took 1,964 seconds (32.7 minutes) plus four seconds of cleanup.
The successful Windows / Python 3.10 job measured 93 seconds after the unit step
and 52 seconds of setup. Combining the observed slow unit step with those
overheads yields a 2,109-second planning envelope, above the old 2,100-second
job cap; it is not a measured whole-job duration. Neither candidate failure is
claimed to be a job timeout. A finite 45-minute unit-job cap adds margin without
omitting tests, adding retries or changing model-request deadlines. Stateful
and advisory caps remain unchanged.

## Limits

No actual-model inference or new model-performance result is asserted here.
Attempt counters mean attempted bounded dispatch, not server receipt or inference;
deterministic stop tests and normal-budget HTTP contracts are distinct evidence.
Local HTTP test services and scripted controls are not model-efficacy measurements.
Receipt hashes bind declared observations to fixture, configuration and local
source; they do not authenticate inference, provider identity, origin or truth.
Errors and incomplete requests never become successful abstention, repair or
zero-cost inference. Temperature zero does not establish determinism; billing
remains unmeasured. The optional evaluators retain their earlier evidence limits.

Public artifacts contain source and sanitized verification only, without private
logs, company data, model paths or credentials. Publication does not update an
active installation or configure a company vault. Actual inference remains
explicit opt-in through the bounded literal-loopback transport.
