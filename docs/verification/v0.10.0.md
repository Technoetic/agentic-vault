proposal fault-injection tests on Windows and macOS. Temporary-directory aliases
(`RUNNER~1` versus `runneradmin`, and `/var` versus `/private/var`) differed from
the product's resolved paths, so test callbacks did not inject their intended
filesystem failures. A deterministic local alias reproduced all four failures and
confirmed that the two paths referred to the same file. The fixture now resolves
its root once; production code and failure/recovery assertions are unchanged.
The hosted rerun is the release gate for this correction.
