# v0.51.0 verification contract

This specifies required gates, not measured pass results. Exact-source results, skips and source identities belong in the release verification.json. Post-publication observations are separate.

## Scope
The release fixes defects from an independent evaluation of v0.50.0 (Windows paths beyond `MAX_PATH` and `path_too_long` error classification, `SessionStart` credential/PEM redaction, Antigravity `Stop` hook deduplication for zero or omitted `executionNum`, zero-issue fresh `/vault-init` scaffolding, test-runner stdin/LF/standalone-import isolation, relocation of `test_rules_inheritance.py` out of engine scripts, safe vault-copy fallback in `vault_doctor.py` and `vault_adapters.py`, root `.gitattributes` LF normalization, and `README.md` / `docs/antigravity.md` structural and version-surface fixes) and adds an opt-in BizRouter Decisions adapter (`skills/agentic-vault/scripts/bizrouter_client.py`, `--provider bizrouter`, `--model`, and `jev_ask.py --escalate-bizrouter`). Python 3.10+ stdlib only. No default network/model calls and no change to the seven certificate-bound checker files.

## Feature evidence
- Opt-in BizRouter Decisions adapter: `test_bizrouter_decisions.py` verifies `noul`, `choice` and 15-level `score` normalization for `google/gemini-decision-1`, 20-question batch limits, shared `jev_client.SENSITIVE` rejection, `jev_ask.py --escalate-bizrouter` selective re-evaluation of `low_confidence`/`low_decisiveness` items (preserving `abstained` items and degrading gracefully when `BIZROUTER_API_KEY` is absent), lazy import compatibility with `vault_connectors.py`, and source-bound `vault_judge.py --provider bizrouter`.
- Windows long paths: `test_windows_long_paths.py` exercises `vault_state.py`, `vault_task_contracts.py`, `vault_runs.py`, `vault_improvements.py` and `backup_vault.py` inside temporary vault paths exceeding 285 characters and verifies `path_too_long` classification.
- Session security and Antigravity Stop deduplication: `test_session_security_and_stop_dedup.py` and `test_antigravity_hooks.py` verify credential and multi-line PEM redaction across `startup`/`compact`/`--host antigravity` (with benign notes byte-identical) and single-checkpoint convergence when `executionNum` is positive, `0` across distinct turns, or omitted across three handlers.
- `/vault-init` cleanliness and isolation: `test_vault_init_cleanliness.py` verifies `issues == 0` and `critical == 0` on fresh template scaffolding (with and without a project minivault), absence of `unreachable_worktree_heads` on `not_vault`/`vault_not_found` early exits, absence of `test_rules_inheritance.py` under `skills/agentic-vault/scripts/`, and crash-free `--help`/`diagnose` when `vault_doctor.py` and `vault_adapters.py` run from `<vault>/00-meta/scripts/`.

## Default-result comparison
Without `--provider bizrouter` or `--escalate-bizrouter`, `jev_ask.py` and `vault_judge.py` preserve the exact v0.50.0 TypeSafe Jev runtime behavior apart from `--help`. Benign `SessionStart` notes remain byte-identical to v0.50.0; only lines matching `jev_client._matches_sensitive` or PEM private-key blocks are replaced. `vault_healthcheck.py` moves its line-2 engine stamp and `ENGINE_VERSION` to `0.51.0`, exempts `rules_dir` contract files from orphan/unindexed counts (keeping section 10 rules checks intact), and omits `unreachable_worktree_heads` when exiting before checking a vault. Seven certificate-bound checker files remain byte-identical from v0.46.0 through v0.51.0, so `checker_sha256` stays `09642e7aa77d0b812f5afa646b491fe2d79d44104e399bea4a3001a6f2f1279d`.

## Required release gates
1. Commit integrated source, focused tests, full fresh local suite (including a long Windows TEMP path run), required offline smoke commands, compilation, whole-tree whitespace, package generation/check, and independent read-only verification.
2. Push candidate branch and obtain nine OS/Python unit and two stateful required CI successes. Advisory supply-chain findings are reported separately.
3. Annotated local tag, UTC0 source ZIP, independent L1/L2 rebuild and blob identity, disposable native Codex installed resource comparison with zero model turns, generated Antigravity package check/isolated install, certificate replay on source and extracted ZIP.
4. Check enabled immutable-release policy and unchanged remote master; push only the tag.
5. Required tag CI passes before progressing.
6. Update Reference Atlas with pinned public citations and independently verify identities, old evidence preservation and generated catalog.
7. Independent release review rechecks final diff, default changes, exact tag/ZIP/install/certificate and CI evidence.
8. Fast-forward remote master to tagged commit after required checks.
9. Required master CI passes.
10. Produce LF verification.json with rebuild_spec and SHA256SUMS from completed observations.
11. Create draft whose body matches the tagged release note, upload exactly the ZIP/verification.json/SHA256SUMS.
12. Download all draft assets and match exact hashes before publishing.
13. Publish immutable Latest.
14. Independently check anonymous downloads, hashes, tag/Latest identity and release/asset attestations. Never rewrite a public tag.

## Boundaries
No company vault or active host installation is upgraded automatically. BizRouter Decisions (`https://api.bizrouter.ai/v1/decisions`) accepts text/JSON payloads only and rejects image/media inputs; neither TypeSafe Jev nor BizRouter is called without `--allow-network` and the corresponding environment variable key. Pattern-based `SessionStart` redaction does not detect arbitrary unlabelled or encoded secrets. Extended-path helpers cover Python stdlib file operations, not external binaries. No live `agy` conversation session is wrapped by an agent.
