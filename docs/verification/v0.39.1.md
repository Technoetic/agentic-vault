## Candidate failure and scope

The unpublished v0.39.0 candidate source
`0b91cb43a4ea4df1ed857b34e52ab8ca4c2029f5` retains failed tag CI run 41660095934.
Its macOS / Python 3.10 unit job ran 2,822 tests with 81 skips and one failure:
the real local HTTP stage timeout produced `transport_error` while the test
required `request_timeout`. No formal v0.39.0 release was published. Other
candidate-job outcomes do not establish results for the patch's final source.

both valid outcomes. The existing runtime already stops later requests after
either native-socket `transport_error` or outer queue `request_timeout`. No
runtime implementation, retry, error classification, action score, model behavior,
installed default, dependency or installed-resource list changes.

## Limits

No actual-model inference or new model-performance result is asserted for this
patch. Scripted controls and local HTTP contract tests are not efficacy evidence.
Receipt hashes bind declared observations to fixture, configuration and local
source; they do not authenticate inference, provider identity, origin or truth.
The earlier optional stage/Korean evaluators retain their evidence boundaries.
Errors and incomplete requests remain failures or omissions, never successful
abstention, repair or zero-cost inference. Temperature zero does not establish
determinism, and billing remains unmeasured.

Public artifacts contain source and sanitized verification only, without private
logs, company data, model paths or credentials. Publication does not update an
active installation or configure a company vault. Actual inference remains
explicit opt-in through the bounded literal-loopback transport.
