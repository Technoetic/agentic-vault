# v0.57.0 verification contract

## Scope

Release `v0.57.0` builds on published `v0.56.0` (`de80d0bf7cd80ab73238ec17539909b44d52c2b3`) by selectively adapting five non-redundant Python standard-library-only evaluation-statistics, recall-hygiene, document-table-sync, multi-turn query-framing, and opt-in decision-API reranking patterns from `ai3inc/opentoolsearch` (`v0.2.1`, commit `7da656db3e57de95fb2bf5a89052430fb3dfdd46`, Apache-2.0; zero new runtime dependencies, no neural embeddings/cross-encoders, no persistent vector caches, no MCP/OpenAI-SDK proxy, no NumPy/SciPy/PyTorch), and removing the embedded `webapp-principles` skill and guide now maintained in standalone `Technoetic/webapp6`:

1. **Paired flat & stratified-macro bootstrap CIs and deterministic 2-fold cross-fitting (`scripts/eval_stats.py`, `scripts/evaluate_recall.py --bootstrap-ci`)**: adds `paired_bootstrap_ci()` (deterministic seed, flat and `(language, scenario)` stratified macro 95% percentile CIs) and `cross_fit_two_fold()` (deterministic SHA-256 balanced 2-fold out-of-fold evaluation) to `scripts/eval_stats.py`, wired via opt-in `--bootstrap-ci` in `scripts/evaluate_recall.py` (descriptive only; gates and exit codes unchanged).
2. **Cross-split near-duplicate query leakage audit and isolated Markdown layout-invariance probe (`scripts/eval_recall_hygiene.py`, `--check-split-leakage`, `--layout-invariance`)**: adds `audit_split_query_leakage()` (`agentic-vault/query-leakage-audit/v1`, normalized exact + word-set and Hangul syllable-bigram Jaccard overlap) and `perturb_markdown_layout()` / `probe_layout_invariance()` (`agentic-vault/layout-invariance-probe/v1`, reordering flat YAML frontmatter keys and varying heading spacing in an isolated temporary copy without touching source vaults), wired via opt-in `--check-split-leakage` and `--layout-invariance` in `scripts/evaluate_recall.py` with redaction support.
3. **Fail-closed JSON-to-Markdown result table synchronization (`scripts/sync_result_tables.py`)**: adds `agentic-vault/table-sync/v1` with `check` (exit `1` on drift, `2` on input/schema error) and atomic LF `write` for `<!-- table:NAME --> ... <!-- /table:NAME -->` blocks, rejecting duplicate JSON keys, `NaN`/`Infinity`, and symlinks/reparse points.
4. **Multi-turn query framing guidance (`commands/vault-recall.md`) and opt-in Stage-2 decision-API candidate reranking (`scripts/rerank_candidates.py`)**: adds concise follow-up query framing guidance to `commands/vault-recall.md` step 5, and adds checkout-only `scripts/rerank_candidates.py` (`agentic-vault/decision-rerank/v1`) performing single-`choice` candidate reranking via TypeSafe Jev (`--provider jev`, `jev-1.13.0`) or BizRouter (`--provider bizrouter`, `google/gemini-decision-1`) with offline `prepare`, network-gated `run --allow-network`, `jev_client.contains_sensitive` blocking, explicit `__none__` abstention, prompt-injection `BOUNDARY`, Stage-1 rank tie-breaking, pure-stdlib optional z-score fusion (`--fuse`), and `external_candidates`-compatible `candidates: [{path, rank}]` output (`role: "advisory"`).
5. **Removal of embedded `webapp-principles` skill and guide**: removes `skills/webapp-principles/`, `docs/webapp-principles.md`, and their generated `antigravity/` copies (now standalone in `Technoetic/webapp6`), updating Codex required skills to `agentic-vault:agentic-vault` (1 skill) and Antigravity CLI package skills from 17 to 16.

None of the seven certificate-bound checker files (`vault_lint_extensions.py`, `vault_warning_policy.py`, `vault_provenance.py`, `vault_egress.py`, `vault_ssot.py`, `jev_client.py`, `vault_paths.py`) change in `v0.57.0`, so `checker_sha256` remains byte-identical to `v0.55.0` and `v0.56.0` (`3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`) on the unchanged harmless corpus (`38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`, `false_positives = 0`).

## Boundaries

- `paired_bootstrap_ci()` and `cross_fit_two_fold()` are descriptive uncertainty tools only; bootstrap CIs on small hand-crafted fixtures do not prove generalization to real-world traffic and never act as gates.
- `audit_split_query_leakage()` detects lexical (word and Hangul syllable-bigram) overlap and does not detect purely semantic paraphrases with disjoint vocabulary.
- `probe_layout_invariance()` tests flat YAML frontmatter key order and heading spacing in an isolated temporary copy; it does not evaluate semantic rewrites or alter the source vault.
- `scripts/rerank_candidates.py` is strictly opt-in (`--allow-network` required for `run`), returns `role: "advisory"` rankings only, and transmits the selected query and candidate descriptions to the chosen provider (TypeSafe Jev or BizRouter) when invoked.
- The `av:webapp-principles` ID in `tests/fixtures/skill_routing/*.json` is a frozen synthetic fixture ID from v0.40.0 and does not represent a shipped runtime skill.
- Live `agy` interactive sessions are not executed by automation.
