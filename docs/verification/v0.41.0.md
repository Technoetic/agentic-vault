# v0.41.0 verification record

Status: preparation; final-source release gates are **pending, not passes**.

## Scope

The release adds optional source-bound ontology definitions, exact reviewed-term
readers and structured definition/slot preflight through a narrow read-only CLI.
Inputs are host-authored declarations and plans, not extracted natural language.
Markdown remains the source. `ready_for_evidence` does not establish available
answer data, semantic truth or authority to execute a query.

The new helpers reuse current source/path/revocation primitives. No existing
default configuration, hook, rule or installed skill description changes. In
`vault_healthcheck.py`, only the release stamp and `ENGINE_VERSION` become
`0.41.0`. No NLP, model, network, database or new runtime dependency is added;
the CLI is not an MCP server. No new model-performance observation is claimed.
Publication does not update active installations or a company vault.

The seven certificate-bound checker files and LF harmless corpus are preserved.
Expected `checker_sha256`:
`be02b141ffed91cbe34f8cb2317a790c60075740bfe5d8dc435ef202f113174f`;
`corpus_sha256`:
`38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`.
These are expected compatibility values, not a claim that final-source replay or
installed-byte verification has already run.

## Implementation evidence

Pending: the release coordinator will record actual feature, metadata and
installed-resource test commands, source revisions, results and environment
skips after inspecting fresh output. Preparation text provides no test total,

regression pass or results on a different platform.

Required feature coverage includes strict schemas/duplicate keys, globally unique
IDs, typed relation direction, exact source proofs, CRLF literal spans, declaration

must reject both changed and missing copies of all three helpers and the guide.

## Evidence boundaries

Hashes bind declared bytes; host review fields do not authenticate a reviewer,
approval, origin or truth. Exact term matching does not infer identity or synonyms.
Complete reviewed definitions and date slots do not prove that business data
exists, is accurate or can answer the proposed question. Unsupported, unreviewed,
ambiguous, stale or blocked input withholds usable context. There is no coverage
percentage, correctness probability, computed value, SQL or executable plan output.

Historical releases and failed candidate records retain their own evidence. No
prior local test, model observation or CI run is relabeled as a v0.41.0 result.
Public artifacts contain source and sanitized verification, not company data or
secrets. Active-installation upgrades and real-vault changes remain separate work.
