# v0.54.1 verification contract

## Scope

Release `v0.54.1` builds on published `v0.54.0` (`2b35dc0635edb453077aecebac5717e05afe25c8`) with four Python standard-library-only security, hygiene, durability, and CI governance fixes (zero new runtime dependencies):

1. **Expanded `Default_Ignorable` invisible Unicode hardening** (citing *Trojan Source* [USENIX Security 2023], *Unicode UTS #39* [Unicode 18.0.0], and *Bad Characters* [IEEE S&P 2022]): `hooks/session_start.py` (`_strip_invisible_smuggling`) and `tests/test_repo_hygiene.py` add seven code points (`U+00AD`, `U+034F`, `U+061C`, `U+200E`, `U+200F`, `U+3164`, `U+FFA0`) so `SessionStart` (`startup`, `compact`, `--host antigravity`) and `vault_doctor.py` strip them before credential redaction and fake-header neutralization while preserving benign Korean/ASCII/emoji text and isolated `_neutralize_header_lines` behavior.
2. **Leading UTF-8 BOM cleanup & CI guard**: strips the 3-byte leading UTF-8 BOM from `docs/knowledge-evolution.md`, `docs/recoverable-bundles.md`, `tests/fixtures/knowledge_evolution/history.json` (and regenerated `antigravity/` mirrors), and enforces no leading UTF-8 BOM across tracked text files in `tests/test_repo_hygiene.py`.
3. **POSIX parent-directory `fsync` durability in `backup_vault.py`** (citing *Pillai et al., OSDI '14*): adds `_sync_dir` (POSIX-only `os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW` + `os.fsync`, ignoring `EINVAL`/`ENOTSUP`/`EOPNOTSUPP`, propagating `EIO`, no-op on Windows) called on `stage`, `snapshots` after `os.replace`, and `destination` + `destination.parent` after `restore_snapshot`.
4. **Advisory SHA-256-verified `actionlint` (`v1.7.12`, MIT) & GitHub Dependabot security updates**: adds checksum-verified `rhysd/actionlint` `v1.7.12` (published `2026-03-30`, past 14-day cool-down, SHA-256 `8aca8db96f1b94770f1b0d72b6dddcb1ebb8123cb3712530b08cc387b349a3d8`) to `.github/workflows/tests.yml` `supply-chain-audit` (read-only `contents: read`, `continue-on-error: true`), updates `tests/test_supply_chain.py`, and enables repository `dependabot_security_updates` (verified via API readback; `secret_scanning_validity_checks` remains `disabled` on this repository tier).

The seven warning-promotion certificate files (`vault_lint_extensions.py`, `vault_warning_policy.py`, `vault_provenance.py`, `vault_egress.py`, `vault_ssot.py`, `jev_client.py`, `vault_paths.py`) remain byte-identical to `v0.46.0..v0.54.0` (`checker_sha256` = `09642e7aa77d0b812f5afa646b491fe2d79d44104e399bea4a3001a6f2f1279d`).

## Boundaries

- `_strip_invisible_smuggling` is deterministic Unicode hygiene, not a prompt-injection sandbox or visual homoglyph detector.
- Direct `jev_client.py` calls remain byte-identical to `v0.46.0..v0.54.0` to preserve `checker_sha256`; `U+034F` (`Mn`) handling inside `jev_client.py` is deferred to the next planned certificate transition release.
- `_sync_dir` executes on POSIX only; Windows directories do not support `O_RDONLY`+`os.fsync`.
- `secret_scanning_validity_checks` remains `disabled` on this repository tier after API PATCH readback.
- Live `agy` interactive sessions are not executed by automation.
