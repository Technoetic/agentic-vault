# v0.53.0 verification

The synthetic retrieval fixture tests both directions of a Korean procedure. A win on only one side is not a pair success. See [inputs, scope and measurements](../ko-order-recall.md). The handoff evaluator uses the same four artifact checks in both arms, and includes wrong-task and stale-input controls. The tutorial test reads command blocks from the published guide. All three checks use standard-library Python and require no model or production data.

Run in a source checkout:

```text
python -m unittest tests.test_korean_order_recall tests.test_handoff_resume_evaluation tests.test_first_handoff -v
python scripts/evaluate_handoff_resume.py demo
python scripts/build_antigravity_package.py check
```

The release receipt lists the commit, CI run, source archive and rebuild specification. Results from a previous release do not count. These tests do not measure human completion time, production retrieval accuracy or the performance of a live model after an interruption.
