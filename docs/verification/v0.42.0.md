# v0.42.0 verification record

Status: preparation; final-source release gates are **pending, not passes**.

## Implementation evidence

The new optional surfaces are recoverable multi-Markdown bundles, a read-only
declared-dependency review planner and a checkout-only generated-memory lifecycle
experiment. Existing direct impact, proof, lesson and revocation semantics are
preserved. Default hooks/configuration and seven certificate-bound checker bytes
remain unchanged. Only the healthcheck release stamp and version constant change.

Focused evidence must cover interrupted replacement before receipt, forward recovery
from actual before/after bytes, unknown-content conflict, lock contention, bounded
strict journals, digest/CAS/policy/source drift and unsafe path rejection. Planner
checks include unchanged downstream claims, diamonds and multiple roots, bounded
shortest explanations, cycles and stable input/source observations. Generated-memory
checks must distinguish actual persistence/reopening, authored content, fresh worker
isolation, feedback-selected bounded poison variants, selective revocation, repair
negative controls, transport budget/failure and source closure rechecks. Scripted
and mock HTTP controls are not actual-model observations. No model is called by
default and no actual-model performance gain is claimed.

Native resource tests must reject missing/changed copies of new helpers and guides.
Fresh focused results, independent review and final full regression counts are
recorded only after actual execution against the exact final source. Preparation
text provides no inherited test total or CI success.

## Evidence boundaries

Dry run is not permission to apply. Journal progress is not target-state authority.
A complete declared graph is not an inferred knowledge graph. A review signal is
not falsehood or editing authority. Selective synthetic repair is not measured
actual-model robustness; hashes authenticate neither provider execution nor truth.
Temporary workers are not a hostile-code OS sandbox. Multi-file atomic visibility,
rollback and universal crash/power-loss durability are outside the bundle contract.
Historical local/native/CI results are not relabeled as this release's results.
Publication does not upgrade installed caches or a company vault.
