# v0.35.1 verification record

## Release content and scope

v0.35.1 retains the webapp-principles skill, canonical six-rule guide and
installed-discovery hardening from the unpublished v0.35.0 candidate, plus
v0.34.0's opt-in diagnostic/evaluation features. It adds a fixture-only backup
test repair on candidate source `35b8543320946736ea0520d648e4a854db260e7c`.
The temporary repository disables automatic Git maintenance and GC with local
`maintenance.auto=false` and `gc.auto=0` before add/commit. Backup runtime code,
fail-closed inventory/link guards and clone assertions remain unchanged.
Final release source identity is recorded in the new pre-publication
`verification.json`, not inferred from the candidate commit.

The three versioned manifests, README/Codex install refs, current support policy
and healthcheck identification advance to 0.35.1. The Codex marketplace entry
contains no version and retains its source mapping. Unchanged rule, hook and
adapter stamps stay at their content versions. The only engine edit in release
preparation is the healthcheck stamp/`ENGINE_VERSION`; no runtime behavior,
default hook, model/network call, dependency, MES or vault upgrade is added.

The native verifier requires both enabled named skills at distinct expected paths
inside the installed package and compares the core skill, secondary skill,
canonical guide and existing resources with source bytes. It preserves the
primary `skill` field, adds `skills`, allows other owned command skills, and keeps
three session-start hooks, one compact hook, one end hook, all untrusted and
zero model turns. These checks establish delivery, not model or app compliance.

## Limits

The skill provides webapp-scoped guidance, preserves existing frameworks and
does not start a workflow or authorize deployment. Native discovery and byte
identity cannot prove agent adherence. Real apps still need the guide's deployment,
dirty/saving input, rollback, transient failure, history/deep-link and data-freshness
matrix. No live installation, vault migration or application update is claimed.
