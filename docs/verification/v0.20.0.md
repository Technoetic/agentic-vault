This release contains five opt-in Tower-inspired reliability additions. Runtime defaults,
Markdown/Git data, standard-library dependencies and explicit caller authority remain in place.
Use [the release notes](../releases/v0.20.0.md) and [the helper guide](../tower-reliability.md).

Public verification of the immutable source is recorded in `verification.json` and `SHA256SUMS`
on [the v0.20.0 release](https://github.com/Technoetic/agentic-vault/releases/tag/v0.20.0).

## Source verification

- Source implementation commit: `238a1fd8823b2497b224edc362c58dc4ba2619e2`.
- Final integration: `python -X utf8 -m unittest discover -s tests -v` ran 1,248 tests in
  331.201 seconds: 1,220 passed, 28 environment/platform skips, zero failures/errors, exit 0.
- Four recall gates (default, advanced, hard top3/top5), deterministic memory workflow,
  compileall and whitespace checks exited 0. Code bytes stayed bound to the tested source.
- Independent current-master documentation/compile-quality verification: 29 passed,
  no skips, 0.372 seconds. Source commit scope, Python bytes and canonical Markdown matched.
- Separate reviewers verified parser/help/ordinary CLI behavior, missing/unsafe adapter
  isolation, same-scenario changed-treatment comparisons, exact-byte undo and explicit
  ingest-exclusion compatibility. Windows junction and hardlink checks actually ran.

The first integrated attempt had 7 failures and 12 errors. Eighteen instances came from
an overbroad new exclusion check in the shared selected-file API; one came from the omitted
new documentation index entry. The shared ingest contract was restored, exclusion checks
were kept in rollback-only paths, regression tests and independent re-review passed,
and the full suite was rerun. Initial failed evidence is retained, not counted as passing.

Release metadata tests, the final local release run and each remote matrix job are recorded
with actual exit codes, immutable source identities and timestamps in the release receipt.
Public ZIP creation uses `git archive` from the final commit; every archived member is
compared with its Git blob. Asset hashes and the public re-download check bind the published files.

## Concurrency and authority limits

An initial Windows two-caller test failed closed on the existing guard path. A final
25-test operation run and 72 repeated two-caller tests passed. A 120-attempt stress test
had 1 claim, 70 blocked and 49 errors, with exactly 1 observed effect. A retained lease
then blocked a sequential call. This establishes a scoped fail-closed observation,
not stable high-load availability, power-loss durability or remote exactly-once execution.
No guard auto-recovery, arbitrary lock deletion or path-policy weakening was introduced.

Receipts bind caller observations and point-in-time file conditions. They do not establish
truth, business quality, action permission, verifier identity or successful live-provider authentication.
No real model turn, Jarvis restart, Telegram message or production-vault migration is claimed.
Rule stamps remain at their last content-change versions. Installed-host verification is a
separate step; publication alone does not update a running session or approve hook trust.
