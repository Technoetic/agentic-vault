# v0.60.0 verification contract

## Scope

Release `v0.60.0` builds on published `v0.59.0` (`0ce51c04924170a0ef5341e4225ee9fe9798a621`) and implements three Python standard-library-only security, policy-integrity, and lifecycle-propagation improvements with zero new runtime dependencies, no automatic network or model calls, and no vault file mutation:

1. **Obsidian `%% ... %%` hidden comments & non-rendered SVG metadata sanitization (`hooks/session_start.py`, `skills/agentic-vault/scripts/vault_doctor.py`)**: grounded in `arXiv:2602.10498v1` ("When Skills Lie: Hidden-Comment Injection in LLM Agents"), extends linear-time `_strip_hidden_markup()` (injected buffer only; vault files untouched) to strip Obsidian single-line, multi-line, and unclosed `%% ... %%` comments, zero-dimension `<svg width="0" ...>` / `<svg height="0" ...>` elements (handling self-closing `/>`), and non-rendered SVG `<desc>`, `<title>`, and `<metadata>` elements strictly inside `<svg>...</svg>` (`svg_depth > 0`). Preserves fenced code blocks, inline code spans, backslash-escaped `\%`, single `%`, and plain-text `<title>`/`<desc>` placeholders outside `<svg>`.
2. **Read-only operator `permissions.deny` monotonicity & hook script SHA-256 drift audit (`skills/agentic-vault/scripts/vault_policy_drift.py`, `skills/agentic-vault/scripts/vault_doctor.py`, `docs/policy-drift.md`)**: grounded in `arXiv:2611.32195v1` ("When Answering Is Administering") and `arXiv:2611.01976v1` ("Beyond Prompt Injection: The Tool Update Gap"), adds sealed baseline recording (`00-meta/.vault-policy-baseline.json`, `baseline_sha256`) and strictly read-only content-free drift checking (`check` and opt-in fail-soft `vault_doctor.py --policy-drift`) for removed `.claude/settings*.json` `permissions.deny` rules (stored only as SHA-256 digests) and modified, missing, unsafe, or untracked hook script SHA-256 digests across settings hooks, vault git hooks, and bundled plugin hooks. Rejects symlinked/junctioned/hardlinked paths and duplicate-key/non-finite JSON fail-closed.
3. **Non-breaking `v0.59.0` `status: withdrawn` / `superseded` propagation to recall & healthcheck (`skills/agentic-vault/scripts/vault_retrieval.py`, `skills/agentic-vault/scripts/vault_recall.py`, `skills/agentic-vault/scripts/vault_healthcheck.py`)**: grounded in `arXiv:2605.14478v1` ("When Retrieval Hurts Code Completion: Stale Repository Context") and `ccf/agentcairn` (Apache-2.0), reads frontmatter `status: withdrawn | superseded` into advanced `temporal.lifecycle_status`, drops `withdrawn` (regardless of `as_of`) and `superseded`-without-`superseded_by` under `--as-of` (`TEMPORAL_REJECTED_STATUSES`, preserving `temporal_filter="annotate_only"` and historical `superseded_by` time-travel), adds opt-in `--exclude-withdrawn` / `--exclude-superseded` to `vault_recall.py`, and adds opt-in `--exclude-retired` / `exclude_retired_from_active_checks` to `vault_healthcheck.py` §7 stale and §8 SSOT conflict checks.
4. **Release-surface & generated `antigravity/` alignment**: aligns manifests, `vault_healthcheck.py` (`engine=0.60.0`), `vault_install_state.py`, `skills/agentic-vault/SKILL.md`, `skills/agentic-vault/references/codex.md`, `scripts/verify_codex_plugin.py`, generated `antigravity/` package (15 skills = 1 shared + 14 commands; 1 Codex required skill; includes `vault_policy_drift.py` and `docs/policy-drift.md`), and documentation to `0.60.0`.

None of the seven certificate-bound checker files (`vault_lint_extensions.py`, `vault_warning_policy.py`, `vault_provenance.py`, `vault_egress.py`, `vault_ssot.py`, `jev_client.py`, `vault_paths.py`) change in `v0.60.0`, so `checker_sha256` remains byte-identical from `v0.55.0` through `v0.60.0` (`3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`) on the unchanged harmless corpus (`38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`, `false_positives = 0`).

## Boundaries

- Buffer-only Obsidian/SVG hidden-markup sanitization is defensive hygiene and does not defeat adaptive prompt injection in visible prose or inline link titles.
- `vault_policy_drift.py` compares static files on disk against a local sealed baseline (`00-meta/.vault-policy-baseline.json`); it does not verify runtime host enforcement or stop an adversary who can overwrite both settings/hooks and the baseline file.
- Lifecycle propagation in `vault_retrieval.py` and `vault_healthcheck.py` inspects only explicit frontmatter `status: withdrawn | superseded`, not prose deprecation notes.
- Live `agy` interactive sessions are not executed by automation.
