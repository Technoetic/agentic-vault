# v0.21.0 verification

The release adds three opt-in MoAI-inspired diagnostics. Existing default Doctor and evidence
interfaces remain compatible; no automatic note edit or production-vault migration is added.
Use [the guide](../moai-diagnostics.md) and [release notes](../releases/v0.21.0.md).

The immutable public `verification.json` and `SHA256SUMS` record actual local commands,
independent review, exact-source CI and archive verification. Public re-download and installed
host verification are later distinct observations, not inferred from a local test.

and adversarial filesystem/manifest cases before release. Failed attempts remain in evidence
and are not counted as passing runs.

## Limits

Static instruction totals do not prove host loading, exact provider tokens, cost or speed.
Index fold plans do not apply; original rows and existing link paths must be reviewed.
Coverage binds declared mappings and caller-reported checks to current evidence; it does not
prove semantic satisfaction, verifier identity or command execution. All reads are bounded,
and runtime host/model effectiveness is unmeasured. Environment exclusions are reported.
