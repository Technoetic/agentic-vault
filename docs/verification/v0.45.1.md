# v0.45.1 verification contract

This document specifies gates, not measured results. Exact-source measurements
and explicit skips belong in the immutable release's `verification.json`; later
public-download/attestation observations belong in separate post-publication evidence.

## Scope

Optional authored literal evidence observation on emitted recall blocks, real
recall in original synthetic vaults, and strict lesson trial observation scoring.
No model/host execution, company inputs, source truth/freshness/authority claim,
causal efficacy certification, default recall change or new production dependency.
Actual-host lesson effectiveness remains unmeasured; scripted examples are not
reclassified as actual-host execution.

## Required feature evidence

- Declared path/line/quote matches attributed emitted blocks only; a same quote
  elsewhere, metadata-only result, wrong line, truncated quote or manufactured
  omission marker cannot satisfy a requirement. Validate bounded malformed data.
- Separate observed/missing requirements, declared blockers, scan scope and output
  completeness. Source hashes are not authenticity or currentness proof.
- Real recall tests include lexical distractors, distributed conditions, shuffled
  records, conflict, no match, context budget and 524288-byte UTF-8 boundary cases.
  Author expected visibility independently; naive any-match control must expose
  false assurance. Existing 512 KiB skip and incomplete status remain unchanged.
- Lesson scoring preserves missing measurements, rejects stale/mismatched bindings,
  separates unpaired/confounded/scripted/caller-reported observations and verifies
  action versus final-result criteria. Injection alone is not behavior improvement.
- New resources are installed and byte-checked in isolated native discovery;
  missing/changed resource negatives must be rejected. Legacy recall fixtures stay
  unchanged. Default hook/config bytes must match the prior source.

## Publication gates

1. Focused and full fresh local unittest; compile, full-tree whitespace checks,
   evaluator controls and independent feature/security review. Preserve failures,
   fixes and explicit platform/dependency skips rather than inventing success.
2. Exact final master and annotated v0.45.1 tag CI: nine OS/Python unit jobs and two
   required stateful jobs per ref. Advisory supply-chain checks remain separate.
3. Claude manifests and actual disposable native Codex source and ZIP discovery,
   installed-resource bytes, hook trust status and zero model turns. Active
   installations and company vaults remain unchanged.
4. Fresh actual seven-file checker fingerprint and LF harmless corpus replay;
   unchanged bytes retain their historical certificates rather than inventing a
   new checksum. Healthcheck version stamp changes with the active version.
5. UTC0 release ZIP, embedded rebuild specification, independent L1 bytes and L2
   member/Git-blob identity, then LF verification.json and SHA256SUMS.
6. Inspect exact three draft assets before immutable Latest publication. Verify
   anonymous public downloads, hashes, Latest/tag identity and release/asset
   attestations after publication. Never rewrite an existing public tag.
7. Update Reference Atlas canonical IDs/aliases and pinned current public uses,
   preserving Sufficient Context and lessons-learned prior-use differences.
   Independently verify the resulting catalog and public source bindings.
