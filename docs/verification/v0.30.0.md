These results describe the implementation commit, not the final release source. Other runtime feature bytes remain the implementation's bytes; unchanged rule stamps remain untouched.

## Final release gates

The pre-publication asset `verification.json` records the fixed final source SHA, actual commands/results and final gate status:

- metadata/README/Codex validation, Claude manifest validation and a disposable Codex installation;
- final master/tag CI on Linux/macOS/Windows and Python3.10/3.12/3.14, plus stateful jobs and advisory audit status;
- baseline compatibility for legacy unbound runs and unchanged core/warning-checker surfaces;
- ZIP built with `TZ=UTC0`, `core.autocrlf=false` and prefix `agentic-vault-0.30.0/`, its `rebuild_spec`, actual L1 byte equality and L2 Git-blob/member equality;
- independent read-only package and frozen-receipt review before publication.

GitHub release immutability is checked before publishing. Release attestation, public re-download hashes, Latest/immutable state and final refs are checked afterward and retained outside the immutable assets in `post-publication.json`. Source-version preparation does not update an active user plugin or actual vault engine.

## Limits

Synthetic tests do not measure actual model accuracy, business effectiveness, complete reporting or savings. Source hashes are integrity links, not authenticated metering, evaluator execution, independence or authorization. Cost comparison availability is separate from native performance eligibility; no efficiency/application decision is made.
