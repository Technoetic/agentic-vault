# v0.58.0 verification contract

## Scope

Release `v0.58.0` builds on published `v0.57.0` (`a478283b71b455e37fe7fef222101abd386c8c37`) together with the already-merged removals of the bundled `/aside-repl` command (PR #25, `b3d88ac133bd49e9d3208a8954dd37ff6b2efab0`) and bundled Jarvis Telegram integration (PR #26, `435425e02735b32c9d806d8e694c3a22ddac3fc1`), and implements three Python standard-library-only security, statistical-evaluation, and refusal-recovery improvements (zero new runtime dependencies, no automatic network or model calls, no vault file mutation):

1. **Hidden Markdown/HTML markup & comment sanitization in `SessionStart` and `vault_doctor` (`hooks/session_start.py`, `skills/agentic-vault/scripts/vault_doctor.py`, citing `arXiv:2611.28763`)**: adds linear-time `_strip_hidden_markup()` right after `_strip_invisible_smuggling()` and before credential redaction / header defusing, mirrored in `vault_doctor.py` injection estimates. Strips HTML comments (single-line, multi-line, and unclosed fail-closed to EOF), Markdown hidden link-reference comments (`[label]: # (...)`, `[label]: <> (...)`, plus indented continuation title lines), and hidden HTML elements (`display:none`, `visibility:hidden|collapse`, `opacity:0`, `font-size:0`, `hidden` attribute, `<script>`/`<style>`/`<template>`) strictly on the in-memory injected buffer while preserving fenced code blocks, inline backtick code spans, normal URL references, and trailing/standalone benign single-token HTML anchors (`<!-- av-v0580-anchor -->`). Revealed fake hook headers (e.g., `<!-- pad -->=== FIXED CONSTRAINTS ===`) are immediately defused by `_neutralize_header_lines()`.
2. **Stdlib-only Holm-Bonferroni FWER adjustment and PPI++ confidence intervals (`scripts/eval_stats.py`, citing `doi:10.2307/4615733`, `doi:10.1126/science.adi6000`, `arXiv:2311.01453`, `arXiv:2601.18777`)**: adds `holm_bonferroni_adjust()` (`agentic-vault/holm-bonferroni/v1`) and `ppi_pp_mean_ci()` (`agentic-vault/ppi-pp-mean/v1`) using only Python 3.10+ stdlib (`math`, `statistics`). Additive and descriptive-only; existing `eval_stats.py` functions and `evaluate_recall.py` defaults/gates/exit codes are unchanged.
3. **Deterministic refusal/confirmation recovery guidance (`assets/adapters/deny-guard/deny-guard.py`, `assets/adapters/deny-guard/ps-parse.ps1`, `skills/agentic-vault/scripts/vault_task_contracts.py`, citing SkillCFI `arXiv:2611.24185`)**: appends deterministic pure-ASCII `Next legal steps: ...` guidance to every `deny`/`ask` reason in `deny-guard.py` (preserving the 3-key `hookSpecificOutput` schema, decision polarity, and pure-ASCII contract; moving both `deny-guard.py` and `ps-parse.ps1` stamps to `engine=0.58.0`) and adds deterministic, content-free `next_legal_steps` lists to `vault_task_contracts.py` result dicts and CLI error payloads.
4. **Bundled `/aside-repl` & Jarvis Telegram removals and release-surface / `antigravity/` alignment**: consolidates PR #25 and PR #26 (`docs/releases/unreleased.md` retired into `docs/releases/v0.58.0.md`), aligning plugin manifests, `vault_healthcheck.py` (`engine=0.58.0`), `vault_install_state.py`, generated `antigravity/` package (15 skills = 1 shared + 14 commands; 1 Codex required skill), and documentation to `0.58.0`.

None of the seven certificate-bound checker files (`vault_lint_extensions.py`, `vault_warning_policy.py`, `vault_provenance.py`, `vault_egress.py`, `vault_ssot.py`, `jev_client.py`, `vault_paths.py`) change in `v0.58.0`, so `checker_sha256` remains byte-identical from `v0.55.0` through `v0.58.0` (`3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`) on the unchanged harmless corpus (`38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`, `false_positives = 0`).

## Boundaries

- `_strip_hidden_markup()` is deterministic hygiene on non-rendered markup channels; it does not prevent visible-text adaptive prompt injection, external stylesheets, or runtime DOM manipulation.
- `holm_bonferroni_adjust()` and `ppi_pp_mean_ci()` are descriptive statistical helpers and never act as pass/fail gates; PPI++ relies on distribution alignment between labeled and unlabeled pools and large-sample normal approximation.
- `Next legal steps:` in `deny-guard.py` and `next_legal_steps` in `vault_task_contracts.py` are advisory recovery hints and not a sandbox or formal control-flow integrity enforcer.
- Live `agy` interactive sessions are not executed by automation.
