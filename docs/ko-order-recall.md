# 한국어 두 단계의 순서를 묻는 검색

노트에 `검수 후 출고`와 `출고 후 검수`가 각각 적혀 있을 때 `검수 다음 출고`로 검색하면 전자를, `출고 다음 검수`로 검색하면 후자를 동점 후보 중 먼저 보여 준다. 선택한 노트에서는 순서가 적힌 줄을 인용한다.

```text
python skills/agentic-vault/scripts/vault_recall.py --vault <vault> --query "출고 전에 검수?"
```

질의는 한글로 된 두 단계 이름(각각 1~32음절) 사이에 독립된 순서 표현 하나를 두는 형태다. `A 후 B`, `A 이후 B`, `A 다음 B`, `A 뒤 B`는 A가 먼저다. `A 전 B`, `A 이전 B`는 B가 먼저다. 각 표현에는 `에`를 붙일 수 있다. 끝의 물음표는 선택 사항이다.

노트에서 같은 단계 이름과 순서가 한 줄에 독립적으로 적혀 있을 때만 그 줄을 근거로 쓴다. 마크다운 제목이나 목록 표시, 끝의 마침표를 허용한다. 같은 노트에 정반대 순서까지 쓰여 있으면 동점을 푸는 근거에서 뺀다. `검수 후 출고 금지` 같은 부정문, 질문, 인용문, 프런트매터, 코드 블록도 이 근거로 쓰지 않는다. 여러 단계가 이어지는 문장, 활용형, 동의어는 기존 어휘 검색으로 처리한다.

기존 읽기 범위와 후보를 그대로 쓰며, 어휘·단어 BM25·한글 2음절 채널에서 원점수가 같을 때 해당 순서를 확인한 후보를 먼저 놓는다. 이 순위가 RRF에 들어가므로 혼합 점수는 바뀔 수 있다. 순서를 묻는 후보가 마지막까지 동점이면 같은 근거를 경로 우선순위보다 먼저 적용한다. 원점수 차이가 있는 단일 채널 순위는 유지한다.

## 두 방향을 모두 맞힌 비율

절차쌍 세 개(검수·출고, 포장·봉인, 검토·승인)를 손으로 작성했다. 각 쌍에 대해 `다음`과 `전에`로 순방향과 역방향을 물었다. 각 설정에는 질의 12개, 두 방향을 모두 맞혀야 성공하는 비교 6개가 있다. 모든 노트 제목은 `순서`이고 파일명에는 단계 이름이 없다.

| 설정 | v0.52.1 1위 정답 | 변경 후 1위 정답 | v0.52.1 양방향 성공 | 변경 후 양방향 성공 |
| --- | ---: | ---: | ---: | ---: |
| 기본 어휘 | 6/12 | 12/12 | 0/6 | 6/6 |
| BM25 | 6/12 | 12/12 | 0/6 | 6/6 |
| BM25 + hangul2 | 6/12 | 12/12 | 0/6 | 6/6 |
| hybrid | 6/12 | 12/12 | 0/6 | 6/6 |

회귀 시험은 `python -m unittest tests.test_korean_order_recall -v`로 실행한다. 위 수치는 이 합성 문형의 결과이며 실제 볼트 질의에서의 빈도와 효과는 별도 측정이 필요하다.

기존 `tests/fixtures/recall_hard`의 한국어 32개·영어 32개 질의도 네 설정으로 양 버전에서 다시 실행했다. 설정별로 상위 5개 검색 결과 전체와 렌더한 문맥을 직렬화해 비교했으며, 네 설정 모두 버전 간 SHA-256이 일치했다.

낱말을 유지하면서 의미가 뒤집히는 예문을 짝짓는 방식은 한국어가 포함된 PAWS-X에서 참고했다. PAWS-X는 번역된 문장쌍의 의미 일치를 평가한다. 이 검색 시험은 절차 노트와 정답 경로를 따로 작성했다. [PAWS-X 논문](https://aclanthology.org/D19-1382/) · [저자 공개 자료](https://github.com/google-research-datasets/paws/blob/02b29f3af1143620d1b7f352247e65c0bdd2ec18/pawsx/README.md)
