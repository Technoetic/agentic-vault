# 다음 릴리스 변경 사항

## 기본 결과 변경

볼트를 초기화하거나 업그레이드할 때 Aside 어댑터는 `/aside-repl` 명령을 설치하거나 갱신하지 않는다. 이전 버전으로 설치했거나 직접 작성한 `.claude/commands/aside-repl.md`는 볼트 사용자가 관리한다. `/vault-doctor`는 이 파일의 복원을 제안하지 않는다.

Aside CLI가 설치된 환경에서는 터미널에서 `aside repl`을 실행할 수 있다. Windows 기동 도우미와 브라우저 어댑터는 계속 사용할 수 있다.

### Telegram 브리지 제거

현재 소스는 Jarvis 브리지와 설정 명령을 배포하지 않는다. Claude Code의 명령은 14개이며, Codex는 공용 스킬을 통해 같은 작업을 사용한다. Antigravity 패키지에는 공용 스킬 하나와 명령 스킬 14개가 들어 있다. 초기화·업그레이드와 연결 진단에서 Telegram 설정을 제안하거나 검사하는 절차도 제거했다.

구판에서 별도로 설정한 Telegram 봇과 토큰, 실행 중인 프로세스, Windows 예약 작업이나 서비스는 운영자가 직접 중지하거나 폐기한다. 플러그인을 바꿔도 사용자 볼트의 기존 설정·수집 노트와 외부 서비스는 자동으로 변경되지 않는다.
