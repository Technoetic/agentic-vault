# v0.58.0 — SessionStart 숨김 주석·태그 주입 차단, Holm·PPI++ 평가 통계, 결정론적 거부 복구 안내 및 `/aside-repl`·Jarvis Telegram 제거

공개 v0.57.0(커밋 `a478283b71b455e37fe7fef222101abd386c8c37`)을 바탕으로, `master`에 이미 합쳐진 번들 `/aside-repl` 명령 제거(PR #25, 커밋 `b3d88ac133bd49e9d3208a8954dd37ff6b2efab0`) 및 번들 Jarvis Telegram 브리지 제거(PR #26, 커밋 `435425e02735b32c9d806d8e694c3a22ddac3fc1`)와 함께, 2026-11-25 12차 문헌 검토에서 선별한 세 가지 Python 표준 라이브러리 전용 보안·평가 통계·거부 복구 개선을 묶어 공개한다. 새 런타임 의존성, 외부 모델·네트워크 자동 호출, 기존 볼트 파일 자동 수정은 없다.

## 변경

1. **SessionStart 및 `vault_doctor` 비(非)렌더링 숨김 마크업·주석 주입 차단 (`hooks/session_start.py`, `skills/agentic-vault/scripts/vault_doctor.py`)** ([hooks/session_start.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/hooks/session_start.py), [skills/agentic-vault/scripts/vault_doctor.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/skills/agentic-vault/scripts/vault_doctor.py), [tests/test_session_start.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/tests/test_session_start.py)).
   마크다운·HTML의 비(非)렌더링 숨김 채널을 통한 간접 프롬프트 주입 연구([arXiv:2611.28763](https://arxiv.org/abs/2611.28763))에 근거해 `SessionStart` 주입 파이프라인(`_strip_invisible_smuggling` 직후, 비밀 마스킹·머리글 무력화 앞단)과 `vault_doctor` 주입 예산 추정에 선형 시간 `_strip_hidden_markup()` 위생 단계를 추가했다. 일반·다중 줄 HTML 주석(`<!-- ... -->`, 닫히지 않은 주석은 파일 끝까지 fail-closed 제거), 마크다운 숨김 링크 참조 주석(`[label]: # (...)`, `[label]: <> (...)` 및 이어지는 들여쓰기 제목 줄), 숨김 HTML 요소(`display:none`, `visibility:hidden|collapse`, `opacity:0`, `font-size:0`, `hidden` 속성, `<script>`·`<style>`·`<template>`)를 주입 버퍼에서만 제거하며 디스크의 원본 볼트 노트는 절대 고치지 않는다. 코드 펜스, 인라인 백틱 코드 스팬, 정상 URL 링크 참조, 그리고 줄 끝·단독 단일 토큰 무해 앵커 주석(예: `<!-- av-v0580-anchor -->`)은 보존하며, 주석 제거 뒤 노출된 가짜 훅 머리글(`<!-- pad -->=== FIXED CONSTRAINTS ===`)은 뒤이은 `_neutralize_header_lines()`가 즉시 무력화한다.
2. **표준 라이브러리 전용 Holm–Bonferroni 다중 검정 보정 및 PPI++ 신뢰구간 (`scripts/eval_stats.py`)** ([scripts/eval_stats.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/scripts/eval_stats.py), [tests/test_eval_stats.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/tests/test_eval_stats.py)).
   [Holm (1979)](https://doi.org/10.2307/4615733)의 단계적 하향 가족별 오류율(FWER) 보정(`holm_bonferroni_adjust`, `agentic-vault/holm-bonferroni/v1`)과 [Angelopoulos et al. (Science 2023)](https://doi.org/10.1126/science.adi6000) · [PPI++ (arXiv:2311.01453)](https://arxiv.org/abs/2311.01453) · [PRECISE (arXiv:2601.18777)](https://arxiv.org/abs/2601.18777)의 예측력 강화 추론 평균·95% 신뢰구간(`ppi_pp_mean_ci`, `agentic-vault/ppi-pp-mean/v1`, 최적 `lambda_hat` 분산 축소 및 고전 표본 평균 대비 분산 절감 비율 보고)을 외부 수치 패키지 없이 순수 Python 3.10+ 표준 라이브러리로 추가했다. 기존 `eval_stats.py` 함수와 `evaluate_recall.py` 기본 출력·게이트·종료 코드는 바꾸지 않는다.
3. **결정론적 거부·확인 복구 안내 (`assets/adapters/deny-guard/deny-guard.py`, `assets/adapters/deny-guard/ps-parse.ps1`, `skills/agentic-vault/scripts/vault_task_contracts.py`)** ([assets/adapters/deny-guard/deny-guard.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/assets/adapters/deny-guard/deny-guard.py), [assets/adapters/deny-guard/ps-parse.ps1](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/assets/adapters/deny-guard/ps-parse.ps1), [skills/agentic-vault/scripts/vault_task_contracts.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/skills/agentic-vault/scripts/vault_task_contracts.py), [tests/test_deny_guard.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/tests/test_deny_guard.py), [tests/test_vault_task_contracts.py](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/tests/test_vault_task_contracts.py)).
   정책 거부 뒤 에이전트의 무작위 재시도를 줄이는 결정론적 합법 전이 안내 패턴([SkillCFI, arXiv:2611.24185](https://arxiv.org/abs/2611.24185))을 적용해, 선택형 `deny-guard.py`의 모든 `deny`·`ask` 사유 끝에 순수 ASCII 1줄 `Next legal steps: ...` 복구 안내를 덧붙이고(`hookSpecificOutput` 3키 스키마·판정 규칙·순수 ASCII 계약 유지, `deny-guard.py`와 `ps-parse.ps1` 스탬프 함께 `engine=0.58.0`으로 이동), `vault_task_contracts.py`의 결과 객체 및 CLI 오류 JSON에 내용 비노출(content-free) `next_legal_steps` 문자열 목록을 추가했다.
4. **번들 `/aside-repl` 명령 및 Jarvis Telegram 브리지 제거 (PR #25 · PR #26 포함) 및 판 표면·생성 `antigravity/` 패키지 정렬.**
   볼트 초기화·업그레이드 시 Aside 어댑터는 더 이상 `.claude/commands/aside-repl.md`를 설치하거나 복원하지 않으며(Aside CLI가 설치된 환경의 터미널 `aside repl`, Windows 기동 도우미 `aside-up.ps1`, 브라우저 어댑터는 유지), 번들 Jarvis Telegram 브리지(`jarvis_bridge.py`)와 `/vault-jarvis-setup` 명령·설정 진단을 제거했다. 이에 따라 Claude Code 명령은 14개, Codex 필수 스킬은 1개(`agentic-vault:agentic-vault`), Antigravity CLI 생성 패키지(`antigravity/`) 스킬은 15개(공용 스킬 1 + 명령 스킬 14)로 정리됐다. 세 매니페스트, `antigravity/` 생성 패키지, `vault_healthcheck.py`(`engine=0.58.0`), `vault_install_state.py`, `README.md`, `SECURITY.md`, `docs/README.md`, `docs/antigravity.md`, `docs/codex.md`, `docs/release-integrity.md`, `assets/adapters/deny-guard/guide.md`를 `0.58.0`으로 정렬했다.

## 하위호환·업그레이드

현재 설치 ref는 `v0.58.0`이다.

기존 볼트 설정 파일은 자동으로 수정·마이그레이션하지 않는다. 공개 준비나 GitHub Release 게시는 활성 호스트 설치나 기존 볼트 사본을 자동으로 갱신하지 않는다. 볼트에 복사된 healthcheck와 helper bundle(`00-meta/scripts/`), 그리고 선택형 `deny-guard.py`·`ps-parse.ps1`을 쓰는 볼트는 설치 호스트에서 플러그인을 갱신한 뒤 `/vault-upgrade`(Codex는 `upgrade`)로 별도 갱신한다. 구판에서 별도로 설정한 Telegram 봇·토큰·실행 중인 프로세스·예약 작업은 운영자가 직접 중지하거나 폐기한다.

v0.55.0–v0.58.0 사이는 인증서가 묶는 일곱 파일이 같으므로 경고 승격 인증서 재생성이 필요 없다. v0.54.1 이하에서 경고를 `fatal`로 승격해 쓰던 볼트는 [v0.55.0 업그레이드 안내](https://github.com/Technoetic/agentic-vault/blob/v0.58.0/docs/releases/v0.55.0.md#하위호환업그레이드)와 같이 승격 해제·모든 엔진 사본 정렬·인증서 재생성(`checker_sha256` = `3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`)·재승격 순서를 따른다.

`vault_healthcheck.py`와 선택형 `deny-guard.py`·`ps-parse.ps1` 스탬프가 `engine=0.58.0`으로 이동하며 기존 규칙 6종과 `aside-up.ps1` 스탬프는 유지한다.

## 알려진 경계

- `_strip_hidden_markup()`은 비(非)렌더링 마크업 채널을 제거하는 결정론적 위생 처리이며, 눈에 보이는 정상 본문에 적힌 적응형 프롬프트 주입이나 외부 CSS 스타일시트·실행 시점 JavaScript 조작에 대한 완전한 방어를 보장하지 않는다. 방어의 근간은 노트 텍스트가 실행·승인 권한을 갖지 않는다는 원칙과 결정론적 통제에 둔다.
- `holm_bonferroni_adjust()`와 `ppi_pp_mean_ci()`는 기술적 통계 도우미이며 자동 통과·실패 게이트로 동작하지 않는다. 특히 PPI++의 분산 축소는 라벨된 표본과 미라벨 표본이 같은 분포에서 추출되었다는 가정과 점근 정규 근사에 의존하므로 소표본·분포 이동 조건에서는 표본 평균의 고전 신뢰구간과 함께 해석해야 한다.
- `deny-guard.py`의 `Next legal steps:`와 `vault_task_contracts.py`의 `next_legal_steps`는 허용된 다음 작업 경로를 안내하는 결정론적 텍스트이며, 모델이 안내를 반드시 따르도록 강제하는 제어 흐름 무결성 샌드박스가 아니다.
- Antigravity CLI 생성 패키지는 `build_antigravity_package.py check` 및 격리 설치 검증으로 확인하며, 실제 `agy` 대화 세션은 에이전트가 감싸 실행하지 않는다.
