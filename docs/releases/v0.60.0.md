# v0.60.0 — Obsidian·SVG 숨김 주석 주입 차단, 운영자 deny 규칙·훅 해시 드리프트 진단 및 철회·대체 노트 회상·헬스체크 비파괴 연동

공개 v0.59.0(커밋 `0ce51c04924170a0ef5341e4225ee9fe9798a621`)을 바탕으로, Python 표준 라이브러리만 사용해 세 가지 보안·무결성·수명주기 연동을 추가했다. 새 런타임 의존성, 외부 모델·네트워크 자동 호출, 기존 볼트 파일 자동 수정은 없다.

## 변경

1. **Obsidian `%% ... %%` 숨김 주석 및 비(非)렌더링 SVG 메타데이터 주입 차단 (`hooks/session_start.py`, `skills/agentic-vault/scripts/vault_doctor.py`)** ([hooks/session_start.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/hooks/session_start.py), [tests/test_v0600_hidden_and_lifecycle.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/tests/test_v0600_hidden_and_lifecycle.py)).
   [When Skills Lie (arXiv:2602.10498)](https://arxiv.org/abs/2602.10498)의 숨김 주석 주입 위협 모델과 v0.58.0 `_strip_hidden_markup()`의 실측 보강에 따라, 선형 시간(`O(N)`) 주입 버퍼 정리기에 **Obsidian Flavored Markdown의 `%% ... %%` 단일행·다중행·미닫힘 주석**(Reading View 비가시) 제거와 **크기 0 `<svg width="0" ...>` / `<svg>` 내부 비렌더링 메타태그(`<desc>`·`<title>`·`<metadata>`)** 제거를 추가했다. 코드 펜스(```` ``` ````·`~~~`), 인라인 코드 스팬, 백슬래시 이스케이프(`\%`), 일반 단일 `%`(예: `100%`), 일반 `<svg>` 외부의 평문 `<title>`/`<desc>` 자리표시자, 원본 볼트 파일은 그대로 보존한다. `vault_doctor.py`는 같은 `_strip_hidden_markup()`을 공유해 토큰 추정을 일치시킨다.
2. **운영자 `permissions.deny` 규칙 단조성 및 설치 훅 SHA-256 드리프트 읽기 전용 진단 (`skills/agentic-vault/scripts/vault_policy_drift.py`, `skills/agentic-vault/scripts/vault_doctor.py`, `docs/policy-drift.md`)** ([skills/agentic-vault/scripts/vault_policy_drift.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/skills/agentic-vault/scripts/vault_policy_drift.py), [docs/policy-drift.md](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/docs/policy-drift.md), [tests/test_vault_policy_drift.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/tests/test_vault_policy_drift.py)).
   [When Answering Is Administering (arXiv:2611.32195)](https://arxiv.org/abs/2611.32195)(권한 응답을 통한 운영자 `deny` 규칙 삭제)와 [Beyond Prompt Injection: The Tool Update Gap (arXiv:2611.01976)](https://arxiv.org/abs/2611.01976)(신뢰 이후 훅·도구 스크립트 코드 변조)를 바탕으로, 봉인된 내용 비노출 기준선(`00-meta/.vault-policy-baseline.json`, `baseline_sha256`) 대비 읽기 전용 드리프트 감사기 `vault_policy_drift.py` (`record` / `check`)와 선택형 `vault_doctor.py --policy-drift`를 추가했다. `.claude/settings.json`·`.claude/settings.local.json`의 `permissions.deny` 규칙 SHA-256 집합 축소·삭제(`deny_rules_removed` · `settings_file_missing`, 새 `deny` 규칙 추가는 단조 강화로 허용)와 설정 훅·git 훅·번들 플러그인 훅 스크립트의 SHA-256 변조·누락·미등록·심볼릭/정션/하드링크(`hook_script_modified` · `hook_script_missing` · `hook_script_unsafe` · `hook_script_untracked`)를 탐지한다. 원문 규칙 문자열·훅 명령줄·예외 문구는 저장하거나 출력하지 않는다.
3. **`v0.59.0` `status: withdrawn`·`superseded` 노트의 회상·헬스체크 비파괴 연동 (`skills/agentic-vault/scripts/vault_retrieval.py`, `skills/agentic-vault/scripts/vault_recall.py`, `skills/agentic-vault/scripts/vault_healthcheck.py`)** ([skills/agentic-vault/scripts/vault_retrieval.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/skills/agentic-vault/scripts/vault_retrieval.py), [skills/agentic-vault/scripts/vault_recall.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/skills/agentic-vault/scripts/vault_recall.py), [skills/agentic-vault/scripts/vault_healthcheck.py](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/skills/agentic-vault/scripts/vault_healthcheck.py)).
   [When Retrieval Hurts Code Completion (arXiv:2605.14478)](https://arxiv.org/abs/2605.14478)(구버전 저장소 문맥 회상의 오류 유발)과 [ccf/agentcairn](https://github.com/ccf/agentcairn)(Apache-2.0, 대체 노트 명시적 구분)을 참고해 `v0.59.0`의 수명주기 상태를 검색과 헬스체크에 비파괴적으로 연결했다. `vault_retrieval.py`는 프런트매터 `status: withdrawn | superseded`를 읽어 고급 모드 `temporal.lifecycle_status`에 표기하고, `--as-of` 지정 시 `withdrawn`(시점 무관)과 `superseded_by` 없는 `superseded`를 `TEMPORAL_REJECTED_STATUSES`로 제외한다(`temporal_filter="annotate_only"` 대조군 보존, `superseded_by`의 미래 `valid_from` 이전 과거 조회 보존). `--as-of` 없이도 동작하는 선택형 `--exclude-withdrawn`·`--exclude-superseded` 플래그를 추가했고, `vault_healthcheck.py`에는 §7 노화·§8 SSOT 모순 집계에서 은퇴(`withdrawn`/`superseded`) 노트를 제외하는 선택형 `--exclude-retired` 플래그 및 `vault-config.json` 키 `exclude_retired_from_active_checks`를 추가했다.
4. **판 표면·문서·생성 `antigravity/` 패키지 정렬.**
   세 매니페스트, `antigravity/` 생성 패키지(15스킬: 공용 1 + 명령 14, `vault_policy_drift.py`·`docs/policy-drift.md` 포함), `vault_healthcheck.py`(`engine=0.60.0`), `vault_install_state.py`, `skills/agentic-vault/SKILL.md`, `skills/agentic-vault/references/codex.md`, `scripts/verify_codex_plugin.py`, `README.md`, `SECURITY.md`, `docs/README.md`, `docs/antigravity.md`, `docs/codex.md`, `docs/note-lifecycle.md`, `docs/release-integrity.md`를 `0.60.0`으로 정렬했다.

## 기본 결과 변경

- **`SessionStart` 및 `vault_doctor` 주입 버퍼 정리 확장:** 코드 펜스·인라인 코드 밖의 Obsidian `%% ... %%` 주석, 크기 0 `<svg>`, `<svg>` 내부 `<desc>`/`<title>`/`<metadata>`가 주입 버퍼에서 제거된다(일반 문서·원본 볼트 파일·단일 `%`·`<svg>` 밖 `<title>`/`<desc>` 평문은 불변).
- **`vault_retrieval.py` `--as-of` 수명주기 반영:** 기본 `vault_recall.py`(플래그 없음)는 기존 레거시 고속 경로 그대로 바이트 단위로 불변이다. 명시적 `--as-of`를 넘길 때 `status: withdrawn` 노트와 `superseded_by` 없는 `status: superseded` 노트가 제외되며, `--exclude-withdrawn`·`--exclude-superseded`는 명시적 선택형이다.
- **`vault_healthcheck.py` 선택형 은퇴 노트 제외:** 기본 실행의 §7·§8 집계와 `--json-summary` 스키마는 v0.59.0과 동일하며, `--exclude-retired` 또는 `exclude_retired_from_active_checks: true`를 켠 경우에만 `withdrawn`/`superseded` 노트를 §7·§8에서 제외하고 `retired_excluded`를 보고한다.
- **`vault_doctor.py --policy-drift` 선택형 진단:** 기본 `vault_doctor.py` 출력과 종료 코드는 불변이며, `--policy-drift`를 넘길 때만 읽기 전용 드리프트 요약을 덧붙인다(fail-soft, 종료 코드 무변경).
- **판 메타데이터:** 매니페스트 버전·설치 태그·healthcheck 스탬프(`engine=0.60.0`, 2행) 및 `vault_install_state.py` 기본 `--engine-version`이 `0.60.0`으로 이동한다. 선택형 `deny-guard.py`·`ps-parse.ps1`은 무변경이므로 `engine=0.58.0`을 유지한다.
- **경고 승격 인증서(`checker_sha256`) 불변:** 인증서가 묶는 일곱 파일은 v0.55.0부터 v0.60.0까지 바이트 단위로 같다(`checker_sha256` = `3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`, harmless corpus 해시 `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`, `false_positives = 0`). v0.55.0–v0.59.0에서 v0.60.0으로 올릴 때는 인증서를 다시 만들 필요가 없다.

## 하위호환·업그레이드

현재 설치 ref는 `v0.60.0`이다.

기존 볼트 설정 파일은 자동으로 수정·마이그레이션하지 않는다. 공개 준비나 GitHub Release 게시는 활성 호스트 설치나 기존 볼트 사본을 자동으로 갱신하지 않는다. 볼트에 복사된 healthcheck와 helper bundle(`00-meta/scripts/`)은 설치 호스트에서 플러그인을 갱신한 뒤 `/vault-upgrade`(Codex는 `upgrade`)로 별도 갱신한다. 정책 드리프트 진단을 쓰려면 신뢰 상태에서 `vault_policy_drift.py record --vault <볼트>`로 기준선을 먼저 기록한다.

v0.55.0–v0.60.0 사이는 인증서가 묶는 일곱 파일이 같으므로 경고 승격 인증서 재생성이 필요 없다. v0.54.1 이하에서 경고를 `fatal`로 승격해 쓰던 볼트는 [v0.55.0 업그레이드 안내](https://github.com/Technoetic/agentic-vault/blob/v0.60.0/docs/releases/v0.55.0.md#하위호환업그레이드)와 같이 승격 해제·모든 엔진 사본 정렬·인증서 재생성(`checker_sha256` = `3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`)·재승격 순서를 따른다.

`vault_healthcheck.py` 스탬프가 `engine=0.60.0`으로 이동하며 기존 규칙 6종, `aside-up.ps1`(`engine=0.17.0`), `deny-guard.py`·`ps-parse.ps1`(`engine=0.58.0`) 스탬프는 유지한다.

## 알려진 경계

- `hooks/session_start.py`의 Obsidian `%% ... %%` 및 `<svg>` 메타데이터 제거는 주입 버퍼 위생 처리이며, 적응형 프롬프트 주입이나 일반 가시 텍스트·인라인 링크 제목(`[text](url "title")`) 공격에 대한 완전 방어가 아니다.
- `vault_policy_drift.py`는 디스크 위 설정·훅 파일 해시와 로컬 봉인 기준선(`00-meta/.vault-policy-baseline.json`)만 정적으로 대조한다. 런타임 호스트 집행을 검증하지 못하며, 설정·훅과 기준선 파일을 동시에 덮어쓸 수 있는 공격자는 막지 못한다.
- `vault_retrieval.py`와 `vault_healthcheck.py`의 은퇴 노트 연동은 명시적 프런트매터 `status: withdrawn | superseded`만 해석하며, 본문 산문으로만 적힌 폐기·대체 선언은 탐지하지 않는다.
- Antigravity CLI 생성 패키지는 `build_antigravity_package.py check` 및 격리 설치 검증으로 확인하며, 실제 `agy` 대화 세션은 에이전트가 감싸 실행하지 않는다.
