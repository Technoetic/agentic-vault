# agentic-vault v0.17.0

날짜: 2026-09-29

선택형 **도구 어댑터**를 더했다. 첫 어댑터는 Aside(AI 브라우저 CLI)다. 엔진 규칙은 여전히
도구 중립이다. 어느 브라우저를 쓰는지는 볼트 CLAUDE.md가 정하고, 어댑터는 Aside가 설치된
볼트에서 그 결정을 사용자 승인 아래 채워 넣는 템플릿과 도우미일 뿐이다. Aside가 없는 볼트의
동작은 바뀌지 않는다.

## 변경

### 엔진 규칙 (`engine=0.17.0`)

- `vault-browser.md` 9번 **창 기반 앱의 수명과 포커스**: 도구가 떠 있는 앱 창에 묶여 있으면
  (창을 닫으면 CLI 데몬도 종료되는 AI 브라우저 등) 명령 전에 CLAUDE.md가 정한 기동 절차로
  앱을 확인·기동한다. 기동할 때 사용자가 쓰는 창의 포커스를 뺏지 않는다. 이미 떠 있는 창은
  최소화·이동·닫기를 하지 않는다. 작업이 끝나도 앱 창을 닫지 말고 연 탭만 닫는다.
- 나머지 다섯 규칙은 내용이 같아 스탬프를 올리지 않았다.

### Aside 어댑터 (`assets/adapters/aside/`)

- `browser-clause.md`: CLAUDE.md 사용자 영역(관리 블록 밖)에 넣는 브라우저 도구 조항.
  `exec`는 페이지 내용을 클라우드 모델로 보내므로 공개 웹 조사에만 쓰고, 외부 전송 금지
  자료는 로컬 `repl`로만 연다. 기동 도우미 사용, 창을 닫지 않기, 제약은 운영 가이드에
  실측으로 기록하기를 담는다. 볼트 소유라 업그레이드가 바꾸지 않는다.
- `aside-up.ps1`(Windows, `agentic-vault:adapter aside-up engine=0.17.0`): Aside가 꺼져 있으면
  띄운 뒤 창이 보이자마자 최소화하고, 기동 직전의 전경 창에 포커스를 돌려준 다음 CLI 응답까지
  기다린다. 이미 떠 있으면 아무 창도 건드리지 않는다. 브라우저는 떠 있는데 데몬만 응답하지
  않으면 다시 실행하지 않는다(새 창이 생겨 사용자 창까지 최소화될 수 있다). `-Hook`에서는
  종료 코드가 항상 0이다. Windows PowerShell 5.1이 BOM 없이 읽도록 ASCII만 쓴다.
- `settings-hooks.json`: Claude Code PreToolUse 훅. `if` 조건 `Bash(aside *)`·`PowerShell(aside *)`
  때문에 aside 명령에서만 실행되고 다른 셸 명령에는 비용이 없다. 훅은 명령을 막지 않는다.
- `operations-guide.md`: `20-knowledge/tools/Aside CLI 운영 가이드.md` 뼈대. 엔진 개발 기기의
  실측 표와 빈 「이 볼트의 실측」 표를 둔다. `status: draft`로 만들고, 그 기기에서 실측한 뒤
  `active`로 바꾼다.

### 명령·스크립트

- `vault_adapters.py`(새 스크립트, 읽기 전용): `aside` CLI가 PATH에 있는지, 도우미 스탬프 상태
  (`missing`·`current`·`outdated`·`newer`·`modified`·`unstamped`·`unreadable`·`unsafe_path`),
  CLAUDE.md 조항 마커, 훅 설정, 운영 가이드 노트를 보고하고 `actions`로 제안할 일을 적는다.
  설치·복사·실행·설정 변경은 하지 않는다. 링크를 거치거나 볼트 밖으로 나가는 경로는 읽지 않는다.
- `/vault-init` 4-1: `aside` CLI가 있을 때만 어댑터를 제안하고, 승인하면 조항·도우미(Windows)·
  운영 가이드 노트를 넣는다. 훅 병합은 Claude Code·Windows에서 따로 확인받는다. Codex에서는
  훅 단계를 생략한다.
- `/vault-upgrade` 6번: 진단의 `actions`에 따라 구버전 도우미를 diff 확인 후 교체하고,
  스탬프가 없거나 로컬 수정된 도우미는 덮어쓰지 않으며, 빠진 부분은 제안만 한다.
- `/vault-doctor` 6번: 어댑터 상태를 함께 보고한다. 기억 주입 판정과 섞지 않는다.

## 하위호환·업그레이드

- Aside CLI가 없는 볼트: 새 파일이 생기지 않고, 진단에 "도구 어댑터 없음" 한 줄만 나온다.
- 기존 볼트는 `/vault-upgrade`(Codex `$agentic-vault:agentic-vault upgrade`)로 `vault-browser.md`
  (`engine=0.12.0` → `engine=0.17.0`)와 생성 AGENTS.md를 갱신한다. healthcheck 스탬프는
  `engine=0.17.0`이다.
- 어댑터 이전에 Aside 조항·도우미를 손으로 만든 볼트는 진단이 `review_helper`(스탬프 없음)로
  보고한다. 업그레이드는 그 파일을 덮어쓰지 않는다.
- Telegram Jarvis 세션은 훅을 끈 채(`disableAllHooks`) 읽기 도구만으로 돌기 때문에 이 훅과
  무관하다.
- Codex 설치: `codex plugin marketplace add Technoetic/agentic-vault --ref v0.17.0`.

## 검증과 경계

- Windows 11 실측(Aside 앱 1.0.928.2, CLI 1.26.916.1741, Claude Code 2.1.252)과 테스트 결과는
  [v0.17.0 검증 기록](../verification/v0.17.0.md)에 있다.
- macOS·Linux에는 기동 도우미가 없다. 포커스를 뺏지 않는 기동 방법을 실측하지 않았으므로
  조항은 앱을 직접 띄우라고만 안내한다.
- 도우미의 창 판별은 Aside 창 클래스(`Chrome_WidgetWin_1`)에 기댄다. Aside가 창 구조를 바꾸면
  최소화가 동작하지 않을 수 있다. 그 경우에도 CLI 준비 확인과 종료 코드는 그대로 동작한다.
- 훅 `if` 조건은 Claude Code 문서의 권한 규칙 문법이다. 조건을 무시하는 호스트에서는 훅이 모든
  Bash·PowerShell 호출마다 실행될 수 있다. 이때도 도우미가 훅 입력의 명령을 다시 확인해 aside
  명령이 아니면 곧바로 끝내므로 Aside를 띄우지 않는다. 다만 호출마다 PowerShell 기동 비용
  (약 0.3~0.5초)이 남는다.
