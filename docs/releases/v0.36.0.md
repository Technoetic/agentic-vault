# v0.36.0 — 선택형 지식 영향·교환·변화 평가

## 변경

- [영향 조회](../knowledge-impact.md)는 명시적으로 등록한 출처·주장·소유 노트의 파일 변화를 읽기 전용으로 확인한다. JSON은 64 KiB 한도이며 출력은 CRLF 재입력 공간을 확보한다. 주장의 진실이나 의미를 판정하지 않는다.
- [OKF v0.2 내보내기](../okf-export.md)는 선택한 노트만 볼트 밖 새 디렉터리에 내보내는 제한된 프로필이다. 원본 frontmatter, 경로 대응, 원본·결과 해시와 손실을 기록한다. 승인 상태를 추정하지 않는다.
- [오프라인 변화 평가](../knowledge-evolution.md)는 다섯 checkpoint와 여섯 주장으로 구성한 합성 이력을 실제 도구로 재생한다. 구조화된 사실의 변화에 대한 시험이며 자연어 의미 추출이나 실제 모델·업무 성능 개선의 측정이 아니다.

OKF 양성 시험의 임시 경로는 `.resolve()`로 정규화한다. macOS `/var` 별칭을 출처/출력 우회 경로와 구별하기 위한 fixture 수정이며 실제 링크 차단 가드는 유지한다.

## 하위호환·업그레이드

세 기능은 명시적으로 실행한다. 기본 훅·회상·런타임 의존성 및 일곱 인증서 묶음 검사기 파일은 변하지 않는다. `checker_sha256`는 `be02b141ffed91cbe34f8cb2317a790c60075740bfe5d8dc435ef202f113174f`, `corpus_sha256`는 `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`다. 실제 설치 바이트가 같다면 v0.35.1과의 전환만으로 인증서 재생성은 필요 없다. 더 오래된 다른 바이트의 전환은 [기존 순서](v0.35.1.md#하위호환업그레이드)를 따른다. 설치 ref는 `--ref v0.36.0`이다. 공개는 활성 설치 갱신이나 볼트 마이그레이션의 권한을 뜻하지 않는다.

## 검증

이전 로컬 전체 시험 관측은 2,671개, 실패·오류 0, 환경 제외 45개이며 세 모듈 재실행을 포함한다. CRLF 수정 후 별도 집중 확인이 있었으므로 이를 최종 소스의 단일 전체 시험 통과로 취급하지 않는다. 최종 CI·설치·ZIP·자산·공개 확인은 [검증 기록](../verification/v0.36.0.md)에 대기 중이다.

## 알려진 경계

해시는 무결성 확인이지 인증이나 서명이 아니다. 내보내기는 전체 OKF 호환을 주장하지 않는다. 합성 평가 결과는 실제 볼트나 실제 모델에 일반화할 수 없다.
