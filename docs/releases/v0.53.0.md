# v0.53.0 — 한국어 절차 검색과 세션 인계 실험

## 기본 결과 변경

한국어로 두 작업의 순서를 명시한 질의에서 어휘 점수가 같은 후보의 순위가 달라질 수 있다. 예를 들어 ‘검수 다음 출고’는 ‘검수 후 출고’를, ‘출고 다음 검수’는 그 반대를 우선한다. 지원하는 표현·적용 채널과 한계는 [검색 예제](../ko-order-recall.md)에 있다. 이 변경은 일반 한국어 의미 이해를 제공하지 않는다. 권한, 읽기 범위, 기본 검색 모드, 네트워크 정책은 바뀌지 않는다.

## 처음 써 보기

[첫 인계 따라 하기](../first-handoff.md)는 소스 체크아웃에서 임시 예제 볼트로 시작한다. 결정·다음 행동·근거 줄을 다른 프로세스에서 찾아본다. 테스트가 안내서에서 명령을 읽어 그대로 실행한다. 10분은 학습 목표이고 신규 사용자 실측 시간이 아니다.

[인계 재개 비교](../handoff-resume.md)는 같은 작업을 이어 한 경우와 다른 업무를 거쳐 재개한 경우의 최종 파일을 같은 기준으로 채점한다. 올바른 인계·잘못된 업무·오래된 입력을 구별한다. 기본 실험은 별도 Python 프로세스를 사용하는 고정 시나리오다. 실제 참여자의 결과를 채점하는 방법도 제공하며 기본 실행이 사람이나 모델의 성능을 뜻하지 않는다.

## 참고한 연구와 오픈소스

- [PAWS-X 논문](https://aclanthology.org/D19-1382/) 및 [저자 자료](https://github.com/google-research-datasets/paws/blob/02b29f3af1143620d1b7f352247e65c0bdd2ec18/pawsx/README.md): 단어가 겹치지만 의미가 다른 대조쌍 설계에서 착안했다. 한국어 검색 사례는 새로 작성했으며 원 데이터셋의 점수를 재현한 것이 아니다.
- [Switch-SWE 논문](https://arxiv.org/abs/2611.02017v1) 및 [저자 구현](https://github.com/Miraclecsc/Switch-SWE/tree/1d9a9ab0b8bf5fec9b730dfc810cfdbe159233ec): 업무 전환 유무를 같은 결과 기준으로 비교하는 방법을 차용했다. 원 벤치마크를 실행한 것이 아니다.
- [Sybil](https://github.com/simplistix/sybil/blob/de4cdc5a24d5c8879bf3db1089924f51bd25c972/docs/markdown.rst#L124-L158): 게시된 Markdown 예제를 시험 입력으로 쓰는 방식을 참조했다. Sybil 설치는 필요하지 않다.

## 하위호환·검증

소스 태그는 `v0.53.0`이다. 새 런타임 의존성이나 볼트 데이터 변환은 없다. healthcheck 버전 스탬프가 바뀌며 기존 설치와 볼트를 게시 과정에서 자동 변경하지 않는다. 기존 스탬프 사본 갱신은 설치 호스트에서 별도로 진행한다. [검증 범위](../verification/v0.53.0.md)와 GitHub Release의 `verification.json`에서 소스 및 실행 기록을 확인할 수 있다.
