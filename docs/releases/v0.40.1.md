# v0.40.1 — canonical temporary setup for macOS tests

v0.40.1 supersedes the **unpublished v0.40.0** candidate. Its tag at source
`f924cab` was pushed, but macOS tag CI failed before a public release was
published. Preserve that tag, failed CI and the original
[v0.40.0 preparation record](../verification/v0.40.0.md); they are historical
evidence, not successful v0.40.1 verification.

## Test-only correction

On macOS, a temporary directory can be exposed through `/var` while its
canonical path is under `/private/var`. Positive routing tests supplied the
alias path to a production policy that deliberately rejects symlink components.
The policy rejected it as designed; the positive test setup assumed a canonical
temporary path without establishing one.

The correction applies `Path.resolve()` to temporary setup paths in tests.
Production evaluator modules, source binding, strict symlink rejection, grading,
limits and CLI contracts remain unchanged. Negative symlink tests still exercise
the rejection boundary. This is a test portability fix, not relaxed production
input validation or evidence of a runtime routing bug.

remain applicable: optional checkout-only multi-skill grading, explicit owned-root
catalog collection, advisory overlap diagnostics and compatible trusted-report
comparison. The 32 original AI-assisted KR/EN synthetic cases and scripted
controls are grader checks, not actual-model routing measurements. No actual-model
inference or live Codex observation adapter is added. Manifest parsing remains a
strict bounded frontmatter subset. Comparison cannot regrade omitted expectations
or authenticate caller-authored grades or host events.

Installation refs target `--ref v0.40.1`. Publication does not update active
installations or a company vault. Python 3.10+ standard-library requirements,
installed skill descriptions, hooks, configuration defaults and earlier
evaluators retain their contracts. The healthcheck changes only its release
stamp and `ENGINE_VERSION` to `0.40.1`; its behavior remains unchanged.

The seven certificate-bound checker files and committed LF harmless corpus
remain outside this patch's behavioral changes. Expected `checker_sha256`:
