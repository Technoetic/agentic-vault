# agentic-vault 0.9.0-local.1

2026-09-05 · 로컬 개선판 · 기준 upstream `74890f6` (v0.8.4)

이 작업본은 원본 프로젝트의 공식 릴리스가 아니다. 기존 Claude Code 플러그인과
Markdown 볼트 구조, Python 3.10+·표준 라이브러리 구성을 유지한다.

## 변경

- **세션 주입:** config와 읽기 경로를 주입 전에 검증한다. 볼트 밖·deny zone·
  심볼릭 링크·정션 경로를 거부하고, hot/handoff의 추정 토큰 예산을 헤더와
  생략 표시까지 포함해 실제 출력에 적용한다. 큰 파일의 읽기량도 제한한다.
- **훅 실행:** resume에서도 주입하며, 사용 가능한 Python을 선택한 뒤 한 번만
  실행한다. 검사 결과가 실패라는 이유로 다른 Python에서 다시 실행하지 않는다.
- **건강 검사:** 전체 스캔의 config·노트·index·rules·보고서 경로에서도 외부
  링크·정션 접근을 차단한다. standalone 배포와 명시적 `--output`은 유지하고,
  변경된 검사기의 engine stamp를 `0.9.0`으로 올린다.
- **백업:** 삭제 동기화 미러를 새로 만들지 않고 독립 스냅샷·SHA-256 manifest·
  Git history bundle을 보존한다. staging 완료 후 공개하며 이전 사본을 자동
  삭제하지 않는다. 검증과 새 디렉터리로의 복구를 추가한다.
- **로컬 검색:** `/vault-recall`이 한국어·영어 질의에 대해 출처 경로·행 번호가
  붙은 발췌문을 반환한다. 어휘 일치 기반의 결정론적 조회이고, 검색·읽기·
  컨텍스트 크기를 제한하며 제한 발생을 진단한다.
- **워크플로:** 세션 복원 시 제한된 출력을 재사용하며 전체 파일 재읽기로
  예산을 우회하지 않는다. 세션 종료는 다른 에이전트의 항목을 부분 수정한다.
- **검증:** 실제 임시 파일·Git 저장소를 사용하는 회귀 테스트, 이중 언어 어휘
  검색 fixture 평가, Windows/Linux/macOS CI 설정을 추가한다.

## 호환성과 사용

기존 config는 유지한다. 예산 **0은 주입 비활성화**이며 절대경로·상위 경로·
링크 경로는 허용하지 않는다. 이전에 이런 설정을 사용했다면 일반 볼트 내부
노트로 옮기고 config를 수정해야 한다. 건강 검사기의 standalone 배포는 유지한다.

백업의 기존 `--vault`·`--target` 인자는 그대로 사용한다. 기존 `mirror/`·
`bundles/`는 삭제하지 않는다. 복구는 기존 경로를 덮어쓰지 않으며 Git 이력은
스냅샷의 `history.bundle`에서 별도로 복구한다. 용량 보존 정책은 사용자가
직접 정하고, 백업 중에는 볼트 쓰기를 멈추는 것이 좋다.

백업은 상위 경로의 링크·정션도 거부하므로 OS 경로 별칭 대신 정규 경로를
사용한다. `.git` 포인터 파일을 쓰는 worktree/submodule, 최초 커밋 전 저장소,
다른 OS에서 복원할 수 없는 파일 이름은 명시적 실패 대상이다.

[전체 사용법과 검증 명령](../reliability.md)을 참고한다. 설치는 로컬 작업본을
marketplace 경로로 지정해야 하며, GitHub 원격 설치는 원본 버전을 설치한다.

## 검증 경계

자동 테스트는 외부 서비스 없이 동작한다. 포함된 recall@3/MRR 평가는 정해진
어휘 검색 fixture의 회귀 지표이며 실제 Claude 답변 정확도나 의미 회상 성능을
나타내지 않는다. CI 설정 추가는 원격 CI 통과와 다르다. 실제 Claude 실세션,
모델 규칙 상속, Telegram 송수신은 별도로 검증해야 한다.

토큰 수는 근사치다. 요약의 사실성·교훈의 타당성은 모델과 사람의 판단에 남는다.
파일 접근 검증은 권한 샌드박스를 대체하지 않는다. 스냅샷은 도구가 덮어쓰지
않는 독립 사본이며 OS 불변 저장소나 암호화 저장소를 뜻하지 않는다.
