# v0.36.1 — 선택형 지식 교환·변경 검토와 시험 fixture 이식성

공개하지 않은 [v0.36.0 후보](v0.36.0.md)의 기능을 유지하고 Windows Python 3.10에서
실패한 시험 fixture를 고친다. 후보 소스 `07d37e543281cbc020da8f9e7119cf498b4c25fe`와
v0.36.0 태그·draft·당시 문서는 보존한다. 이 패치는 새 소스와 태그의 검증을 요구한다.

## 변경

- `test_macos_publish_uses_rename_exclusive`는 `os.name`을 `posix`로 모킹하기 전에
  경로 객체를 만든다. Windows Python 3.10에서 모킹된 전역 `os.name`을 보고
  `Path('/tmp/source')`가 지원하지 않는 `PosixPath`를 만들던 시험 오류를 피한다.
  macOS의 `renamex_np` 호출·플래그 검증은 유지한다. 제품의 내보내기 코드·원자적
  게시 방식·링크 차단 가드는 바꾸지 않는다.
- v0.36.0의 [명시 관계 영향 조회](../knowledge-impact.md),
  [선택 노트 OKF v0.2 교환](../okf-export.md),
  [오프라인 합성 변화 평가](../knowledge-evolution.md)를 유지한다.
  64 KiB 입력·CRLF 출력 예약, 원본 frontmatter·매핑·해시·손실 보고,
  다섯 checkpoint·여섯 claim의 합성 시험이라는 범위도 같다.
- 세 매니페스트와 healthcheck 버전 식별은 0.36.1로 맞춘다. 실제 동작 수정은
  시험 fixture에 한정하며 기본 훅·회상·런타임 의존성은 유지한다.

## 하위호환·업그레이드

설치 ref는 `--ref v0.36.1`이다. 일곱 인증서 묶음 검사기 파일과 harmless corpus는
v0.35.1 및 v0.36.0 후보와 같다. `checker_sha256`는
`be02b141ffed91cbe34f8cb2317a790c60075740bfe5d8dc435ef202f113174f`,
`corpus_sha256`는 `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`다.
설치 바이트가 일치하면 이 전환만으로 인증서를 다시 만들 필요가 없다.
더 오래된 다른 bound 바이트와 오갈 때는
[기존 업그레이드·롤백 순서](v0.35.1.md#하위호환업그레이드)를 유지한다:
fatal 승격을 warning으로 되돌리고, 모든 엔진 사본을 맞춘 뒤 harmless replay를
포함해 인증서를 재생성하고 다시 승격한다.

공개는 활성 플러그인 설치 갱신이나 회사 볼트 변환의 권한을 추가하지 않는다.

## 검증

v0.36.0 [태그 CI 실행 41270505587](https://github.com/Technoetic/agentic-vault/actions/runs/41270505587)의
[Windows/Python 3.10 작업](https://github.com/Technoetic/agentic-vault/actions/runs/41270505587/job/124742126579)은
Python 3.10.11에서 `NotImplementedError: cannot instantiate 'PosixPath' on your system`으로
실패했다. 2,672개 시험·오류 1·제외 16·1072.136초 관측이며 공개 게이트 통과가 아니다.
기존 구현의 2,671개 모듈 재실행 반영 집계도 새 소스의 단일 전체 시험으로 취급하지 않는다.

최종 소스 검증, master/tag CI, 플랫폼별 전체 시험, 설치·ZIP·자산·공개 후 확인은
[v0.36.1 검증 기록](../verification/v0.36.1.md)의 별도 게이트다.
문서 준비 시점에는 대기 중이며 이전 후보의 부분 통과 결과로 대신하지 않는다.

## 알려진 경계

선택형 내보내기는 전체 OKF 호환 인증이 아니다. 해시는 무결성 확인이며 신뢰·서명·승인을
증명하지 않는다. 합성 fixture 결과는 실제 업무·모델 효과를 측정하지 않는다.
