# v0.21.0 — 지침량·인덱스 정리·요구별 검증 누락 진단

MoAI-ADK의 세 설계를 기존 Doctor·기억·근거 흐름에 맞춰 선택형 도구로 구현한다.
Python 표준 라이브러리를 사용하며 upstream Go 코드는 복사하지 않았다.
[사용법과 입력 계약](../moai-diagnostics.md), [검증 기록](../verification/v0.21.0.md),
[공개 자산](https://github.com/Technoetic/agentic-vault/releases/tag/v0.21.0)을 함께 확인한다.

## 변경

- **지침량 진단:** Doctor `--instructions`에서 AGENTS 우선/CLAUDE fallback,
  로컬 참조와 중첩 규칙의 분량·조건·누락을 확인한다. 본문을 출력하지 않는다.
  정적 문자량이며 실제 호스트 로드·제공자 토큰·비용 측정이 아니다.
- **완료 인덱스 정리 미리보기:** 명시한 완료 ID·원문 행·해시·기존 목적지를 검증하고
  원문을 보존하는 정리 계획을 반환한다. 중복·충돌·근거 변경·도달 불가를 확인한다.
  적용·이동·삭제 기능은 제공하지 않는다.
- **요구별 검증 누락 확인:** 요구·인수 조건·필수 검사 목록을 제출한 결과와 별개로
  선언한다. 빠진 연결·검사·통과 결과와 변경된 근거를 진단한다. 기존 evidence를
  사용하며, 연결이 있다는 사실만으로 의미 충족·검사 실행·검증자 신원을 인증하지 않는다.

## 하위호환·업그레이드

새 도구는 명시적으로 호출한다. Doctor 기본 출력과 기존 evidence 호출 계약,
기억 검색·비교·복구 동작을 유지한다. 기본 네트워크/모델 호출을 추가하지 않는다.
healthcheck stamp/ENGINE_VERSION은 0.21.0으로 맞추며 내용이 같은 여섯 규칙의
마지막 변경 스탬프는 유지한다. 플러그인 설치와 실제 볼트 upgrade는 별개다.
Jarvis API 인증과 기존 경로·출처·권한 정책은 유지한다.

## 검증

실제 로컬 회귀·독립 검토·최종 Git source의 원격 CI 결과는
[검증 기록](../verification/v0.21.0.md)과 공개 `verification.json`에 남긴다.
ZIP은 최종 Git commit에서 만들고 모든 멤버를 blob과 대조한다.
공개 자산을 다시 내려받아 SHA256SUMS와 일치하는지 확인한다.

## 알려진 경계

지침 목록은 호스트의 현재 컨텍스트를 관측하는 이벤트 로그가 아니다. 조건과 로드
후보를 구분하며 한도·참조 누락이 있으면 완전한 총량으로 주장하지 않는다.
인덱스 미리보기는 실제 인덱스를 줄이지 않으며 완료 상태는 작성자 선언이다.
요구 매핑과 통과 표시는 작성자 관찰과 현재 파일 바인딩이지 업무 품질 인증이 아니다.
실제 비용·속도·모델 품질 개선은 이번 구현으로 측정하지 않았다.
