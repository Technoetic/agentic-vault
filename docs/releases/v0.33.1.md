# v0.33.1 — macOS 양성 시험 fixture의 임시 루트 정규화

## 변경

v0.33.0은 macOS CI의 시험 fixture 실패로 공개하지 않은 후보였다. 공개 기준판은 v0.32.0(`4462490`)이다. 기존 v0.33.0 태그·draft·[릴리스 문서](v0.33.0.md)·[검증 문서](../verification/v0.33.0.md)는 당시 후보 기록으로 보존하고 새 버전으로 진행한다.

macOS에서 `/var`는 `/private/var`로 이어질 수 있다. 두 평가기의 양성 시험 fixture가 `TemporaryDirectory`의 논리 경로를 그대로 사용하면 엄격한 linked-parent 거부가 정상 경로도 거부하는 시험 결과를 냈다. fixture의 임시 루트를 `Path(...).resolve()`로 정규화해 실제 경로를 사용한다. 의도적으로 링크를 만드는 거부 시험과 제품의 엄격한 런타임 경로 가드는 유지한다. 제품 평가기·SSOT 로직은 바꾸지 않는다.

v0.33.0 후보에 준비했던 다음 기능을 포함한다.

- [상태·의존성 변경 평가](../state-revision-evaluation.md): 독립 합성 사례·산술 의존성과 구조화한 관측 재생.
- [근거 부족 평가](../evidence-insufficiency-evaluation.md): 근거 부족 인정과 근거 없는 전제 부정의 구분.
- [선택형 행 진단](../support-row-diagnostics.md): `check-support --row-references`의 파싱한 모든 행 참조·감사 모집단과 `--bind-subject`의 같은 물리 줄 주어·값 관측. 기존 지원 판정·`warnings`와 분리한다.

세 매니페스트·healthcheck 식별은 `0.33.1`, Codex 고정 설치 ref는 `--ref v0.33.1`이다. 규칙·어댑터의 불필요한 스탬프 변경은 없다. 모델·네트워크 호출·자동 볼트 갱신을 추가하지 않는다.

## 하위호환·업그레이드

`checker_sha256`는 미공개 v0.33.0 후보와 같은 `af8f4c5ab9fc809a4998e55870e769d5f617d6742a53d0c5c2844df7ff3d7b92`이며, 공개 v0.32.0의 `9bca12a79bfa87ff2bf44afecb2e5527e19c199b95fc1435d9513d2be73b3563`와 다르다. 시험 fixture·문서·healthcheck 버전 식별은 일곱 bound 파일 밖에 있다. 실제 설치 바이트로 확인하며 버전 이름만으로 호환을 판단하지 않는다.

Claude Code와 Codex의 플러그인 설치본, 그리고 git 볼트에서 pre-commit 훅이 실행하는 볼트 안 엔진 사본(`00-meta/scripts/`)이 그 대상이다. 그래서 경고를 `fatal`로 올린 볼트는 갱신 전에 다음 순서를 따른다. 이전 버전으로 되돌릴 때도 같은 순서다.

1. 볼트 설정 `warning_policy.levels`에서 `fatal`로 올린 단계를 `warning`으로 되돌린다.
2. 볼트를 읽는 엔진을 모두 같은 버전(되돌릴 때는 이전 버전)으로 바꾼다. Claude Code와 Codex 설치본을 함께 바꾸고, git 볼트의 엔진 사본은 갱신할 때 `/vault-upgrade`(Codex `upgrade`)로 바꾼다. `/vault-upgrade`는 사본을 이전 버전으로 내리지 않으므로, 되돌릴 때는 그 사본도 이전 버전의 파일로 직접 되돌린다.
3. 바꾼 설치본에서 `vault_warning_policy.py --certificate`로 인증서를 다시 만들어 볼트 설정의 `warning_policy.certificate`에 넣는다. harmless replay 결과를 확인한다.
4. 단계를 다시 `fatal`로 올린다.

## 검증

기존 구현 `e9d382a`의 Windows 전체 2,537개·skip 43과 v0.33.0 후보의 집중 시험·기본 출력56건·CLI15건은 당시 근거다. v0.33.0의 실패한 macOS CI를 PASS로 바꾸어 기록하지 않는다. v0.33.1의 최종 소스·플랫폼별 시험 수와 제외 수·CI·설치·ZIP 재현·draft·공개 게이트는 새 `verification.json`과 외부 `post-publication.json`의 실제 결과로 확인한다. 문서 준비 시점에는 이 최종 게이트가 대기 중이다. [v0.33.1 검증 기록](../verification/v0.33.1.md)을 함께 본다.
