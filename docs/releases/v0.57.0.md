# v0.57.0 — 짝 부트스트랩·2-폴드 교차 적합 통계, 질의 누수·레이아웃 불변 위생, 결과 표 동기화, 선택형 결정 API 재정렬 및 `webapp-principles` 분리 제거

공개 v0.56.0(커밋 `de80d0bf7cd80ab73238ec17539909b44d52c2b3`)을 바탕으로 [`ai3inc/opentoolsearch`](https://github.com/ai3inc/opentoolsearch)(`v0.2.1`, 커밋 `7da656db3e57de95fb2bf5a89052430fb3dfdd46`, Apache-2.0)에서 선별한 다섯 가지 비(非)중복 평가 통계·위생·문서 동기화·후속 질의 보완·선택형 결정 API 재정렬 패턴을 Python 표준 라이브러리만으로 구현하고, 독립 저장소 [`Technoetic/webapp6`](https://github.com/Technoetic/webapp6)로 분리된 내장 `webapp-principles` 스킬과 문서를 제거해 공개한다. 신경망 임베딩·크로스인코더 모델 다운로드, 영속 벡터 캐시, MCP/OpenAI-SDK 프록시, NumPy·SciPy·PyTorch 의존성은 도입하지 않으며, 새 런타임 의존성과 모델·네트워크 자동 호출은 없다.

## 변경

1. **평면·층화 매크로 짝 부트스트랩 95% 신뢰구간 및 결정론적 2-폴드 교차 적합 (`scripts/eval_stats.py`, `scripts/evaluate_recall.py --bootstrap-ci`)** ([scripts/eval_stats.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/eval_stats.py), [scripts/evaluate_recall.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/evaluate_recall.py), [tests/test_eval_stats.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/tests/test_eval_stats.py)).
   `eval_stats.py`에 결정론적 시드 기반 평면 및 `(언어, 시나리오)` 층화 매크로 95% 백분위 짝 부트스트랩 신뢰구간(`paired_bootstrap_ci`)과 결정론적 SHA-256 균형 2-폴드 교차 적합(`cross_fit_two_fold`)을 추가했다. `evaluate_recall.py --compare --bootstrap-ci`는 `paired_randomization`과 같은 비점검(headline) 쌍에 대해 기술적 95% 신뢰구간을 덧붙이며, 게이트와 종료 코드를 바꾸지 않는다.
2. **dev/held-out 분할 간 근사 중복 질의 누수 감사 및 마크다운 레이아웃 불변성 프로브 (`scripts/eval_recall_hygiene.py`, `--check-split-leakage`, `--layout-invariance`)** ([scripts/eval_recall_hygiene.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/eval_recall_hygiene.py), [scripts/evaluate_recall.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/evaluate_recall.py), [tests/test_eval_recall_hygiene.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/tests/test_eval_recall_hygiene.py)).
   `audit_split_query_leakage`는 정규화 완전 일치와 단어 집합·한글 음절 2-gram Jaccard(기본 문턱 `0.60`)로 dev와 held-out 분할 간 근사 복사 질의 누수를 탐지한다(`agentic-vault/query-leakage-audit/v1`). `perturb_markdown_layout`·`probe_layout_invariance`는 정책 허용 노트만 격리된 임시 사본으로 복사해 평면 YAML 프런트매터 키 순서와 제목 공백을 의미 보존 변형한 뒤 원본 볼트를 건드리지 않고 Top-1·Top-k 순위 일치를 측정한다(`agentic-vault/layout-invariance-probe/v1`). 두 검사는 `evaluate_recall.py`의 선택 플래그(`--check-split-leakage`, `--layout-invariance`)와 가명화(`--redact`)에 연결되며 기본 실행과 게이트에 영향을 주지 않는다.
3. **JSON 평가 결과 → 마크다운 결과 표 fail-closed 동기화 (`scripts/sync_result_tables.py`)** ([scripts/sync_result_tables.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/sync_result_tables.py), [tests/test_sync_result_tables.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/tests/test_sync_result_tables.py)).
   문서 안의 `<!-- table:NAME --> ... <!-- /table:NAME -->` 블록을 JSON 명세(`schema_version: 1`)와 원본 JSON 지표에서 결정론적으로 렌더링해 대조(`check`, 드리프트 시 종료 코드 `1`, 입력·스키마 오류 시 `2`)하거나 마커 밖 서술을 보존한 채 LF 원자 갱신(`write`)한다. 중복 JSON 키, `NaN`/`Infinity`, 심볼릭 링크·재분석 지점을 fail-closed로 거부한다(`agentic-vault/table-sync/v1`).
4. **멀티턴 후속 질의 보완 지침 (`commands/vault-recall.md`) 및 선택형 2단계 결정 API 후보 재정렬 (`scripts/rerank_candidates.py`)** ([commands/vault-recall.md](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/commands/vault-recall.md), [scripts/rerank_candidates.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/scripts/rerank_candidates.py), [tests/test_rerank_candidates.py](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/tests/test_rerank_candidates.py)).
   `/vault-recall` 5단계에 대명사·생략이 많은 후속 질문은 직전 턴에서 사용자가 명시한 핵심 주제·문서명을 `--query`에 함께 넣어 자기완결적인 어휘 질의로 다듬도록 안내를 추가했다. 또한 체크아웃 전용 선택 도구 `scripts/rerank_candidates.py`(`agentic-vault/decision-rerank/v1`)를 추가해 TypeSafe Jev 직접 API(`--provider jev`, `jev-1.13.0`) 또는 BizRouter(`--provider bizrouter`, `google/gemini-decision-1`)의 단일 `choice` 호출로 후보(`--candidates` 기본 25건·상한 50건, `--catalog` 최대 200건)를 재정렬한다. 오프라인 `prepare`와 명시적 `--allow-network`가 필요한 `run`을 분리하고, `jev_client.contains_sensitive` 비밀 검사·명시적 `__none__` 기권·프롬프트 인젝션 경계·동률 시 1단계 순위 보존·순수 표준 라이브러리 z-score 융합(`--fuse`)·`vault_retrieval` 호환 `candidates: [{path, rank}]` 사이드카 출력을 제공한다(`role: "advisory"`).
5. **내장 `webapp-principles` 제거 및 판 표면·생성 `antigravity/` 패키지 정렬.**
   독립 저장소 [`Technoetic/webapp6`](https://github.com/Technoetic/webapp6)로 분리된 `skills/webapp-principles/`와 `docs/webapp-principles.md`를 제거했다. 이에 따라 Codex 필수 스킬 검증은 `agentic-vault:agentic-vault` 1개로, Antigravity CLI 생성 패키지(`antigravity/`) 스킬은 17개에서 16개로 정리됐다. 세 매니페스트, `antigravity/` 생성 패키지, `vault_healthcheck.py`(`engine=0.57.0`), `vault_install_state.py`, `scripts/build_antigravity_package.py`, `scripts/verify_codex_plugin.py`, `README.md`, `SECURITY.md`, `docs/README.md`, `docs/antigravity.md`, `docs/codex.md`, `docs/hardening.md`, `docs/skill-routing-evaluation.md`, `docs/release-integrity.md`를 `0.57.0`으로 정렬했다.

## 기본 결과 변경

- **내장 `webapp-principles` 제거 (의도된 구성 변경):** `skills/webapp-principles/SKILL.md`와 `docs/webapp-principles.md`, 생성 패키지의 `antigravity/skills/webapp-principles/`와 `antigravity/docs/webapp-principles.md`가 제거된다. 웹앱 6원칙 스킬이 필요하면 독립 저장소 [`Technoetic/webapp6`](https://github.com/Technoetic/webapp6)를 별도로 설치해 사용한다. Codex `verify_codex_plugin.py`의 필수 스킬 목록은 `agentic-vault:agentic-vault` 1개, Antigravity CLI 스킬 수는 16개다.
- 판 메타데이터: 매니페스트 버전·설치 태그·healthcheck 스탬프(`engine=0.57.0`, 2행)·`ENGINE_VERSION` 및 `vault_install_state.py` 기본 `--engine-version`이 `0.57.0`으로 이동한다.
- `evaluate_recall.py`: `--bootstrap-ci`, `--check-split-leakage`, `--layout-invariance`를 주지 않은 기본 실행과 `--compare`의 JSON 스키마·키 집합·지표·종료 코드는 v0.56.0과 같다.
- **경고 승격 인증서(`checker_sha256`) 불변:** 인증서가 묶는 일곱 파일은 v0.55.0·v0.56.0과 바이트 단위로 같다(`checker_sha256` = `3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`, harmless corpus 해시 `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`, `false_positives = 0`). v0.55.0·v0.56.0에서 v0.57.0으로 올릴 때는 인증서를 다시 만들 필요가 없다.

## 하위호환·업그레이드

현재 설치 ref는 `v0.57.0`이다.

기존 볼트 설정 파일은 자동으로 수정·마이그레이션하지 않는다. 공개 준비나 GitHub Release 게시는 활성 호스트 설치나 기존 볼트 사본을 자동으로 갱신하지 않는다. 볼트에 복사된 healthcheck와 helper bundle(`00-meta/scripts/`)은 설치 호스트에서 플러그인을 갱신한 뒤 `/vault-upgrade`(Codex는 `upgrade`)로 별도 갱신한다. 기존에 `agentic-vault`에 내장돼 있던 `webapp-principles` 스킬을 사용하던 환경은 v0.57.0 갱신 뒤 독립 플러그인 [`Technoetic/webapp6`](https://github.com/Technoetic/webapp6)를 별도로 설치한다.

v0.55.0–v0.57.0 사이는 인증서가 묶는 일곱 파일이 같으므로 경고 승격 인증서 재생성이 필요 없다. v0.54.1 이하에서 경고를 `fatal`로 승격해 쓰던 볼트는 [v0.55.0 업그레이드 안내](https://github.com/Technoetic/agentic-vault/blob/v0.57.0/docs/releases/v0.55.0.md#하위호환업그레이드)와 같이 승격 해제·모든 엔진 사본 정렬·인증서 재생성(`checker_sha256` = `3754f606efe8d48c55d5a835bf78552dc9deb6379673d883c5cb9eb56010e79d`)·재승격 순서를 따른다.

healthcheck만 `engine=0.57.0`으로 이동하며 기존 규칙 6종·어댑터 스탬프는 유지한다.

## 알려진 경계

- `paired_bootstrap_ci`와 `cross_fit_two_fold`는 기술적 불확실성 요약이며, 소표본 설계 fixture에 대한 부트스트랩 신뢰구간은 실제 운영 트래픽의 통계적 일반화를 보장하지 않는다(게이트나 종료 코드로 쓰지 않는다).
- `audit_split_query_leakage`는 단어·한글 음절 2-gram 어휘 중복을 탐지하며 어휘가 전혀 다른 순수 의미적 패러프레이즈는 탐지하지 못한다.
- `probe_layout_invariance`는 평면 YAML 프런트매터 키 순서와 제목 공백 변형에 대한 검색 순위 안정을 관찰할 뿐, 본문 문장 재작성이나 의미 보존을 증명하지 않는다.
- `scripts/rerank_candidates.py`는 기본 오프라인이며 `--allow-network`가 명시될 때만 호출한다. 반환된 순위는 `role: "advisory"` 참고값이며 실행 승인이나 진실 판정이 아니고, 외부 API 전송 시 선택한 질의와 후보 설명이 해당 공급자(TypeSafe Jev 또는 BizRouter)로 전송된다.
- `tests/fixtures/skill_routing/*.json`의 `av:webapp-principles` 항목은 v0.40.0부터 고정된 합성 라우팅 테스트 픽스처 ID이며 설치되는 실제 스킬을 뜻하지 않는다.
- Antigravity CLI 생성 패키지는 `build_antigravity_package.py check` 및 패키지 검증으로 확인하며, 실제 `agy` 대화 세션은 에이전트가 감싸 실행하지 않는다.
