# agentic-vault v0.13.0 릴리스 노트

날짜: 2026-09-20

행동별 승인·기록·금지 조건을 설정으로 선언할 수 있도록 `gates` 스키마를 추가했다.
이번 릴리스는 설정 형식 검증을 제공한다. 실행 시 사용자 확인이나 행동 차단을 자동 집행하지 않는다.

## 변경

- 선택 설정 `gates`: `confirm`·`log`·`deny`는 boolean, `repeat`·`probation_days`는 0 이상의 정수, `note`는 문자열이다. 알 수 없는 필드와 잘못된 타입, 빈 행동 이름·빈 정책 객체를 거부한다.
- 행동 이름은 앞뒤 공백을 제거한다. 정규화 후 이름이 겹치면 설정 오류로 거부하여 먼저 선언한 정책이 덮어써지는 것을 막는다.
- 새 볼트 템플릿에 노트 생성·이동·삭제, 교훈 승격, 로컬 커밋·로컬 미러 push·네트워크 push, 외부 전송의 8개 예시를 추가했다.
- healthcheck 스탬프와 `ENGINE_VERSION`을 `0.13.0`으로 올려 기존 볼트의 엔진 갱신 대상이 되도록 했다. README와 Codex 설치 안내의 현재 버전도 맞췄다.

## 하위호환·업그레이드

Python 3.10+와 표준 라이브러리 구성을 유지한다. `gates`가 없거나 `{}`·`null`이면 빈 정책으로 정규화된다. 이미 `gates`라는 사용자 정의 설정을 쓰던 볼트는 새 스키마와 맞는지 확인해야 한다. 잘못된 설정은 healthcheck에서 거부되며 세션 주입도 중단될 수 있다.

플러그인 갱신 후 기존 볼트의 standalone 검사기를 갱신하려면 `/vault-upgrade` 또는 Codex `$agentic-vault:agentic-vault upgrade`를 사용한다. 로컬 수정이 있는 검사기는 자동 덮어쓰지 않는다. 일반 누락 키 보충은 `gates`가 없으면 템플릿 예시를 추가할 수 있고, 이미 있는 사용자 값은 유지한다. 기존 rules 및 git 훅 스탬프는 바꾸지 않았다.

Claude Code는 기존 마켓플레이스와 플러그인을 갱신한다. Codex 신규 설치:

```text
codex plugin marketplace add Technoetic/agentic-vault --ref v0.13.0
codex plugin add agentic-vault@agentic-vault-local
```

기존 Codex 설치는 [등록 소스 교체 절차](../codex.md#설치)를 따른다. 새 버전을 로드하려면 Claude Code를 재시작하거나 Codex 새 대화를 연다.

## 검증

전체 테스트와 독립 검토 결과는 [v0.13.0 검증 기록](../verification/v0.13.0.md)에 남긴다. 행동 정책 테스트는 타입·허용 필드·정규화 충돌·입력 복사 독립성·템플릿 유효성을 검사한다.

## 알려진 경계

- `confirm`·`log`·`repeat`·`probation_days`·`deny`는 선언만 검증한다. 실행 시 승인 요청·기록·반복 횟수·관찰 기간·행동 차단은 미연동이다.
- 기존 pre-push 훅의 네트워크 원격 차단은 `gates`와 독립적으로 동작한다. `gates`를 바꾸어도 훅 권한이 바뀌지 않는다.
- `gates`는 새 권한을 부여하거나 사용자의 기존 지시·볼트 행동 계약을 대체하지 않는다.
