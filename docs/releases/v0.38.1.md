# v0.38.1 — 기억 출처 보존·모델 평가의 Windows 시험 보완

v0.38.1은 공개하지 않은 [v0.38.0 후보](v0.38.0.md)의 기능을 유지하고,
Windows Python 3.10에서 드러난 시간 측정 시험의 잘못된 가정을 수정한다.
실패한 후보 태그와 CI 기록은 보존하며 기존 태그를 다시 쓰지 않는다.

## 수정한 시험

빠른 로컬 HTTP 응답은 해상도가 낮은 단조 시계에서 `latency_seconds: 0.0`으로
관측될 수 있다. v0.38.0의 시험은 이를 반드시 양수여야 한다고 잘못 가정했다.
시간 관측이 유한한 음이 아닌 값인지 검사하고, 같은 시계 눈금 안에서 요청이
완료되는 회귀 사례로 실제 응답·사용량·해시가 정상 보존되는지 확인한다.
양수로 보이게 가짜 시간을 더하지 않으며 런타임·요청 제한·실패 집계는 바꾸지 않는다.

[CPython 3.10의 Windows 구현](https://github.com/python/cpython/blob/3.10/Python/pytime.c#L882)은
`GetTickCount64()`와 시계 해상도를 사용한다. 경과 시간 0은 요청 실패와 구분한다.

## 유지하는 기능

- [출처·역할 보존](../memory-trust.md): 호스트 역할, 정확한 원문 해시와 인용,
  별도 관측을 연결한다. 가짜 역할·성공 문구 자체로 지시나 검증 경험이 되지 않는다.
  결과는 참고용이며 `authorization_granted: false`다. 호출자의 신원·진실·실행을 인증하지 않는다.
- 원본 영·한 합성 대조군: 가짜 승인·성공 경험과 정상 기억 보존, 오류를 나눠
  검사한다. JSON 재준비는 직렬화 모의시험이며 실제 모델 요약·일반 공격 차단률이 아니다.
- [선택형 모델 평가](../model-memory-lifecycle.md): 실제 저장·철회·재주입과 후속
  행동을 비교한다. 기본은 모델 없는 대조군이고 실제 추론은 명시한 루프백 서버만
  사용한다. 공식 Inspect 어댑터는 아니며 새 런타임 의존성을 추가하지 않는다.

## 하위호환·업그레이드

설치 ref는 `--ref v0.38.1`이다. 기본 훅·설정·회상·모델/네트워크 호출은 유지한다.
Python 3.10+ 표준 라이브러리만 사용한다. 공개·활성 설치 갱신·회사 볼트 적용은 별도다.

일곱 certificate-bound 검사기와 커밋된 LF harmless corpus는 v0.37.0과 같다.
`checker_sha256`: `be02b141ffed91cbe34f8cb2317a790c60075740bfe5d8dc435ef202f113174f`.
`corpus_sha256`: `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`.
실제 bound 바이트가 같으면 이번 전환만으로 인증서를 다시 만들 필요가 없다.
기존 Windows checkout은 clean git 상태에서도 CRLF corpus를 유지할 수 있어 실제
바이트를 확인한다. 오래된 바이트가 다른 전환은 경고 승격 해제 → 엔진 사본 정렬 →
harmless replay 포함 인증서 재생성 → 재승격 순서를 유지한다.

## 검증 범위와 한계

이전 구현 체크포인트 `9d55755b8e039404147485f0cd900367febb148e`의 로컬 전체
2,789개는 2,742개 통과·47개 환경 제외·실패/오류 0이었다. 그 체크포인트의 작은
합성 기억에서 Qwen 응답 16개를 관측했지만 엄격한 오염 계획 채택은 확인되지 않아
복구 성공 수는 0·효과 판정 보류다. 이 관측을 최종 수정판 소스의 새 모델 측정이나
실제 업무 효과로 해석하지 않는다.

v0.38.0 후보의 두 CI 실행에서는 Windows Python 3.10의 위 시간 가정 시험이
각각 한 건 실패했다. 다른 환경의 통과를 최종 수정판의 검증으로 대신하지 않는다.
최종 수정판 CI·격리 설치·인증서·압축본·독립 검수는
[검증 기록](../verification/v0.38.1.md)의 새 게이트다. 준비 문서의 대기는 통과가 아니다.

호스트가 신고한 역할·관측을 인증하는 전역 경계가 아니며 자연어 의미의 위조를
모두 탐지하지 않는다. 모델 평가의 서버 캐시·숨은 상태·실제 청구 비용은 통제하거나
측정하지 않는다. 출처 재연결 후보·Markdown 구조 검증은 이번 범위에 포함하지 않는다.
