# agentic-vault v0.10.0 릴리스 노트

날짜: 2026-09-07

기억이 왜 주입되지 않았는지 진단하고, 반복 교훈의 수정안을 검토한 뒤 안전하게
적용할 수 있게 했다. v0.9.0에서 남았던 Windows Jarvis 동시 캡처 오류도 수정했다.

## 변경

- **Memory Doctor:** `/vault-doctor` 또는 Codex `$agentic-vault:agentic-vault doctor`.
  설정 오류·누락·빈 파일·예산 0·잘림·경로 차단과 실제 주입 예정량을 구별한다.
  기존 훅의 설정·읽기·렌더링 규칙을 공유하며, 기억 원문이나 보고서 파일을 만들지 않는다.
- **교훈 수정안:** 기존 사용자 소유 Markdown 한 파일의 원문·후보·해시·결정·적용 이력을
  보존한다. `propose` → `inspect` → `check` → `apply ID --approve`로 연결하고,
  대상이 달라지면 적용을 중단한다. 파일 교체 후 기록 저장 실패는 재시도로 확인·정리한다.
  [사용법과 경계](../lesson-proposals.md)를 따른다.
- **Windows Jarvis:** 동시 폴더 생성 중 한 경로에만 `\\?\` 접두사가 남아 볼트 밖으로
  오판하던 문제를 수정했다. OS가 해석한 경로의 비교용 표기만 통일하고, 실제 I/O 경로와
  쓰기 직전의 재확인·볼트 밖 쓰기 차단은 유지한다. 로컬 드라이브와 UNC 경로를 검사한다.

## 하위호환·업그레이드

Python 3.10+·표준 라이브러리 구성과 config 스키마는 유지한다. 플러그인 업데이트만으로
새 진단·교훈 도구를 사용할 수 있으며, 기존 볼트의 CLAUDE.md·AGENTS.md·설정·rules를
덮어쓰는 마이그레이션은 필요하지 않다. 내용이 바뀌지 않은 healthcheck와 rules 스탬프도
유지한다. 새 스킬·명령을 읽으려면 Codex 새 대화 또는 Claude Code 재시작이 필요하다.

Claude Code는 기존 `agentic-vault` 마켓플레이스에서 플러그인을 갱신한다. Codex 신규
설치는 아래 태그를 사용하며, 기존 로컬 설치의 소스·활성화 범위·훅 신뢰 상태는 유지한다.

```text
codex plugin marketplace add Technoetic/agentic-vault --ref v0.10.0
codex plugin add agentic-vault@agentic-vault-local
```

## 검증

검증 명령·실제 결과·독립 검증자는 [v0.10.0 검증 기록](../verification/v0.10.0.md)에
기록한다. 1차 구현 당시의 실패와 수정 경위는 [이전 기록](../verification/openclaw-phase1.md)에
보존한다. 로컬 검사와 원격 CI, 설치본 발견 여부는 각각 구분해 보고한다.

## 알려진 경계

- Doctor는 파일과 설정에서 예상되는 결과를 진단한다. 호스트의 훅 신뢰·실제 실행·모델의
  기억 사용을 증명하지 않으며, 진단만 요청하면 수리를 수행하지 않는다.
- `--approve`는 이미 받은 사용자 승인을 기록한다. 제안 문구나 해시는 사람의 신원이나
  승인을 인증하지 않는다. 엔진 관리 파일·블록, 새 파일, 여러 파일 변경은 적용 대상이 아니다.
- 파일별 원자 교체와 협조하는 실행기 잠금이다. 외부 편집기가 최종 검사 직후 쓰는 상황을
  OS 수준에서 차단하지 않는다. 부분 수정만 허용하는 공유 handoff/tasks에는 사용하지 않는다.
- 링크·권한 보존의 실측 범위와 플랫폼별 제외 항목은 검증 기록에 남긴다. 실제 모델 대화와
  Telegram 송수신, 자동 훅 신뢰 변경은 이 릴리스 검증에 포함하지 않는다.
- 출처 계보와 업그레이드 사전 검사는 후속 범위다.
