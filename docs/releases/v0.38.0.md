# v0.38.0 — 기억 출처 보존·선택형 모델 평가

## 변경 사항

- [기억 신뢰 경계](../memory-trust.md): 호스트가 구분한 원본 발언 역할과 정확한
  UTF-8 해시·인용을 보존한다. 외부 본문의 가짜 사용자 역할 표식이나 `safe`·`validated`
  자기 주장만으로 사용자 지시·검증 경험으로 승격하지 않는다. 별도 호스트 관측도
  신고 정보다. 지원 판정은 근거 연결에 대한 참고 결과이며 `authorization_granted: false`다.
- 원본 영·한 합성 대조군에서 역할 표식·성공 경험·정상 기억 보존·오래된 증명·
  예산/파서 오류를 구분한다. 취약군과 전체 삭제군으로 실패 검출도 확인한다.
  반복 JSON 준비는 직렬화 모의시험이지 실제 모델 요약 시험이 아니다.
- [선택형 모델 복구 평가](../model-memory-lifecycle.md): 실제 캡처·교훈 저장·기억
  조립·철회·선언된 옛 사본 재주입을 새 프로세스에서 실행해 후속 행동을 비교한다.
  기본은 모델 없는 대조군이다. 실제 모델은 명시한 리터럴 루프백 주소와 별도
  네트워크 플래그가 있어야 사용한다. 회사 자료·비밀 파일·외부 모델을 자동 탐색하지 않는다.
- 격리 Codex 설치 검증에 새 도구·평가기·안내 문서 바이트를 추가했다.
  CI의 새 두 명령도 모델 호출 없는 대조군이다.

## 하위호환·업그레이드

설치 ref는 `--ref v0.38.0`이다. 기본 세션 훅·설정·회상·원문 저장을 유지한다.
기본 모델/네트워크 호출과 런타임 의존성은 추가하지 않는다. Python 3.10+ 표준
라이브러리만 사용한다. Inspect AI의 데이터/풀이/채점 분리는 설계 참고이며
공식 Inspect 어댑터나 Inspect 런타임 설치 기능은 아니다.

v0.37.0의 일곱 certificate-bound 검사기와 커밋된 LF harmless corpus는 유지한다.
`checker_sha256`: `be02b141ffed91cbe34f8cb2317a790c60075740bfe5d8dc435ef202f113174f`.
`corpus_sha256`: `38efaabde0ce1e1df4008276db9761ba1b88eff35ddd91cb8d4fc4899023d04a`.
실제 설치 바이트가 같으면 이번 전환만으로 인증서를 다시 만들 필요가 없다.
기존 Windows checkout은 clean git 상태에서도 CRLF corpus를 유지할 수 있어 실제
바이트를 확인한다. 더 오래된 바이트가 다른 설치로 전환할 때는 경고 승격 해제 →
엔진 사본 정렬 → harmless replay 포함 인증서 재생성 → 재승격 순서를 유지한다.
공개와 활성 설치 갱신·회사 볼트 적용은 별도다. 기존 태그는 바꾸지 않는다.

## 검증 범위

구현 체크포인트 `9d55755b8e039404147485f0cd900367febb148e`의 로컬 전체
2,789개 중 2,742개 통과·환경 제외 47개·실패/오류 0이었다. 새 기능 시험 50개와
설치 검사 1개를 포함한다. 고정 합성 대조군의 9사례·표적 8개·정상 주장 19개는
해당 시험의 개수이며 일반 모델 공격 차단률이 아니다.

같은 구현 체크포인트의 ASCII 고정 기억에서 Qwen3.5-9B-Q8_0의 실제 응답 16개를
관측했다(형식 오류 0). 최초 행동이 사전에 정한 오염 계획과 달라 엄격한 복구 효과
판정은 보류했고 복구 성공 수는 0이다. 이를 버전 준비 뒤 최종 소스의 새 모델 측정이나
실제 회사 업무 효과로 표시하지 않는다.

최종 소스의 master/tag CI, 각 OS/Python 결과, 격리 설치·인증서 재생·ZIP/Git blob
대조·독립 재빌드·초안 자산 검수는 [최종 검증 기록](../verification/v0.38.0.md)의
별도 게이트다. 준비 문서의 대기 항목은 통과가 아니다. 게시 전 근거는
`verification.json`, 게시 후 새 다운로드와 증명은 불변 자산 밖 `post-publication.json`에 남긴다.

## 알려진 경계

호스트가 제공한 역할·관측을 인증하지 않으며 호출자는 메타데이터를 위조할 수 있다.
해시·정확한 인용 일치는 권한·내용의 진실·실제 실행을 보증하지 않는다. 임의 호스트의
압축기 전체를 고치거나 자연어 의미의 출처 세탁을 모두 탐지하는 전역 보안 경계가 아니다.
모델 평가는 고정 기억의 한 번짜리 요청이며 모델이 스스로 만든 기억이나 숨은 서버
상태·캐시를 통제하지 않는다. 실제 청구 비용과 일반 보안 성능은 미측정이다.
출처 재연결 후보·Markdown 구조 검증은 이번 공개 범위에 포함하지 않는다.
