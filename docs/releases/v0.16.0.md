# agentic-vault v0.16.0

날짜: 2026-09-25

긴 작업 규율을 공통 규칙과 명령 문서에 더했다. Anthropic의 Opus 5.5 활용 가이드
(claude.dev, 2026-09-22)의 권고 가운데 모델과 무관하게 파일 기반 기억 계층에 해당하는
것만 골라 반영했다. 계속 진행·페어 프로그래밍 같은 협업 스타일과 모델 선택·속도·사고량
설정은 사용자 CLAUDE.md와 호스트 설정의 몫으로 남긴다.

## 변경

### 엔진 규칙 (`engine=0.16.0`)

- `vault-workflow.md` 8번 **긴 작업은 파일로 추적**: 여러 단계 작업은 활성 프로젝트 tasks
  노트의 Now 아래 하위 체크박스(프로젝트가 없으면 `00-meta/scratch/step_archive/`)로 적고,
  진행 위치는 대화 기록이 아니라 파일로 판단한다. 긴 실행에서 대화가 요약돼도 파일은 남는다.
  체크는 메인 세션만 하며, 조회·진단만 요청받은 세션에서는 tasks 노트에 단계를 적거나 추적
  파일을 만들지 않는다.
- `vault-workflow.md` 안전 규칙: 커밋하지 않은 노트를 지우거나 되돌리는 git 명령
  (`git reset --hard`·`git clean`·`git checkout -- <경로>`·`git restore`(작업 트리))과 로컬
  미러를 포함한 강제 push(`--force`·`-f`·`--force-with-lease`·`+<refspec>`)를 노트 삭제로 보고
  먼저 확인받는다.
  `/vault-init`이 git을 노트의 유일한 복구 수단으로 안내하므로, 이 명령들을 노트 삭제와 같은
  확인 대상으로 묶었다.
- `vault-collab.md`: 서브에이전트 보고는 주장으로 취급한다. 인용한 노트 경로·행을 직접
  대조한 것만 노트·hot·handoff에 사실로 쓰고, 나머지는 `미확인`으로 남긴다. 여럿을 동시에
  돌릴 때는 쓰기 대상 노트를 나눈다.

### 명령·템플릿

- `/vault-session-end`: handoff 섹션 목록을 템플릿과 같은 `▶ NEXT / §1 / §2 / §3`으로
  정합했다(구판 `§4 다음 세션 지시사항`은 ▶ NEXT로 취급한다). ▶ NEXT 항목마다 **완료 기준**을
  적는다. 멈춤 조건은 사용자가 밝힌 경우에만 `사용자 지정 멈춤:`으로 그대로 옮기며,
  handoff 문구는 실행 권한이 아니다.
- `/vault-session-end` §9 종료 보고: **사용자 결정 필요 → 변경 → 발견·생략** 순서로 쓴다.
  승격·롤백 제안, 병합 전 충돌, handoff §2 항목을 맨 위에 두며, 승격 제안은 §5의 초안
  (기존 파일 승격은 `inspect`의 실제 diff)을 요약하지 않고 그대로 붙인다. 볼트 CLAUDE.md
  사용자 영역에 종료 보고 형식이 있으면 그것을 따른다.
- `/vault-session-end` §5: 승격 초안은 확인할 명령·체크리스트·금지 패턴·완료 기준 같은
  실행 가능한 조항으로 쓰고, '신중히 생각하라' 같은 사고량·태도 지시는 내지 않는다.
- `/vault-session-start`: 다음 작업 후보가 ▶ NEXT와 완료 기준을 가리킨다. 사용자가 이
  명령과 함께 할 일을 이미 말했으면 되묻지 않고 착수한다. ▶ NEXT는 후보이지 착수 승인이 아니다.
- `/vault-trace`: 보고에 **확인하지 못한 것**(미확인 표시와 실제로 찾아본 범위)을 넣고,
  저장하는 노트에도 미확인 표시를 유지한다.
- `/vault-recall`: 근거가 부족할 때 사용한 검색어(대체 검색어 포함)를 밝힌다.
- `/vault-lint` §4 **상태 노트 교차 대조**: hot·handoff 노트와, handoff와 같은 프로젝트
  폴더의 context·tasks·decisions 노트만 경로 검증 후 읽고, 수치·날짜·이름·상태 모순을 양쪽
  원문 인용과 `파일:행`으로 올린다. 요일 불일치는 결정적 계산으로 확인된 것만 올린다. 임의로
  한쪽을 고르지 않으며 health_report와 exit 판정에는 넣지 않는다. 섹션 8(`ssot_facts`)은 그대로다.
- `/vault-process-inbox`·`/vault-ingest`: 이미지·스크린샷·차트 원본은 파일 자체를 판독해
  위치가 의미를 만드는 정보까지 본문 텍스트로 옮기고, 확실히 읽히지 않는 값은 `(미확인)`으로
  둔다. 인박스 정제 노트에는 원본 임베드를 남긴다. 호스트가 이미지를 읽지 못하면 그 파일은
  인박스에 남긴다. 원본 격리 위치(`_processed/`)는 그대로이며, 이동은 같은 이름의 파일을
  덮어쓰지 않는 방식으로 하고 충돌은 보류로 보고한다.
- `/vault-upgrade`: 답을 받지 못한 항목을 `승인 대기(기존 유지)` 상태로 표 맨 위에 보고한다.
- Telegram Jarvis 정기 브리핑 프롬프트가 handoff의 '인간의 확인이 필요한 사항'에도 주목하고,
  최우선 미결에서 사용자 결정·승인 대기를 먼저 쓰게 했다. 형식(3항목·12줄)과 실행 인자는
  그대로다. `/vault-jarvis-setup`과 README에 텍스트가 아닌 메시지는 응답·로그 없이 무시된다는
  안내를 더했다.
- 템플릿: handoff ▶ NEXT 안내에 완료 기준을, tasks에 긴 작업 하위 체크박스 규칙을 더했다
  (새 볼트·새 프로젝트에만 적용된다).
- 문서: `docs/reliability.md`에 안전 장치의 모델 전환과 세션 주입의 관계를 적었다. 주입된
  handoff/hot 때문에 새 세션에서도 전환이 반복될 수 있을 때 원인을 가르는 방법이며, 실제 판정
  동작은 확인하지 않았다.
- 정합 수정: `/vault-init`이 AGENTS.md를 rules 5개(browser 누락)로 생성하던 문구를 6개로,
  `/vault-upgrade`의 생성 AGENTS 검증 문구(rules 다섯 본문)를 여섯으로 고쳤다. SKILL.md·
  memory-tiers의 옛 handoff 섹션 명칭을 ▶ NEXT로, `/vault-init`의 검사기 스탬프 안내
  (`engine=0.8.2` 고정)를 실제 스탬프 기준으로 바로잡았다. SECURITY.md 한국어 요약과 README의
  Jarvis 설명에 남아 있던 "볼트 훅이 실행·로드된다"는 문구를 `disableAllHooks`로 훅이 꺼진다는
  v0.15.1 동작에 맞췄다.

## 하위호환·업그레이드

- 두 엔진 규칙의 스탬프가 `engine=0.16.0`으로 올라간다(workflow는 0.8.3, collab은 0.6.0에서).
  기존 볼트는 `/vault-upgrade`(Codex는 `$agentic-vault:agentic-vault upgrade`)로 두 규칙을
  교체하고 생성 AGENTS.md를 재생성한다. 나머지 네 규칙의 스탬프는 그대로다.
- 명령 문서 변경은 플러그인 갱신만으로 적용된다. 볼트 노트·config 키·훅 정의는 바뀌지
  않는다. 기존 handoff·tasks 노트는 편집하지 않으며, 구판 `§4 다음 세션 지시사항` 섹션은
  ▶ NEXT로 읽는다.
- healthcheck 검사 내용은 바뀌지 않았다. 스탬프 = `ENGINE_VERSION` = 매니페스트 버전 정합
  규칙에 따라 스탬프가 0.16.0으로 올라가므로 `/vault-upgrade`가 설치된 검사기 교체를 제안할
  수 있다.
- Jarvis를 쓰는 경우 실행 중인 브리지는 플러그인을 갱신한 뒤 재시작해야 새 브리핑 프롬프트가
  적용된다(예약 작업이 옛 설치 경로를 가리키면 브리지 경로도 갱신한다).
- 릴리스 태그 설치는 `--ref v0.16.0`을 사용한다. 플러그인 갱신 후 새 호스트 세션을 연다.

## 검증과 경계

[검증 기록](../verification/v0.16.0.md)을 참고한다. 새 조항은 모델이 따르는 산문 규칙이며
기계적으로 강제되지 않는다. 교차 대조와 이미지 판독은 에이전트 판독이라 결정론적이지 않고,
기존 pre-commit·pre-push 훅과 healthcheck가 계속 기계적 게이트다. 규칙이 컨텍스트 요약 뒤에도
유지되는지, 서브에이전트 보고 대조가 실제 세션에서 지켜지는지는 이 릴리스에서 측정하지 않았다.
