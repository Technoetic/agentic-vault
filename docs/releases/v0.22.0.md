# v0.22.0 — 한국어 기억·상태 변경·도구 호출 평가

기억을 찾는 것과 올바르게 답하는 것을 구분하고, 파일 상태 변경과 실제 모델의 도구
호출을 별도로 검사할 수 있는 선택형 개발·평가 도구를 추가한다.
[사용법](../memory-evaluation.md), [구현 관측](../verification/memory-evaluation-20261016.md),
[릴리스 검증](../verification/v0.22.0.md)을 함께 확인한다.

## 변경

- **한국어 평가 50문항:** 현재·과거·조건·답 없음·출처 철회 사례에서 검색 근거와
  제한된 구조화 답변을 따로 채점한다. 오답·구정보 대조군과 관측 재생을 지원한다.
- **상태 기반 회귀:** 실제 proposal/operation API에 생성된 작업 순서를 적용해
  오래된 상태, 충돌, 적용·복구와 중복 쓰기 방어를 검사한다. Hypothesis는 개발
  의존성이며 기본 런타임에 추가되지 않는다.
- **합성 도구 호출 평가:** `tools`/`tool_calls`를 사용하는 제한된 실행 루프에서
  정상 과제 성공, 공격 목표 달성, 차단 시도, 모델·통신 오류를 구분한다. 실제
  모델은 명시한 loopback endpoint로만 호출하고 메시지 전송은 메모리 속 가상함이다.
- CI에 모델 없는 평가와 두 OS/Python 조합의 상태 기반 회귀를 추가한다.
  Windows의 UTF-8 JSON 출력과 가상환경용 실행 파일 시험 fixture도 보완한다.

## 하위호환·업그레이드

기본 세션 주입·검색·정책·네트워크/모델 호출·런타임 의존성을 늘리지 않는다.
healthcheck의 stamp/ENGINE_VERSION은 0.22.0으로 맞추며 내용이 같은 여섯 규칙의
스탬프는 유지한다. 플러그인 배포, 설치 캐시 갱신, 실제 볼트 upgrade는 별개다.
기존 Jarvis API 인증 조건은 유지한다. 설치는 README 또는 Codex 안내의
`--ref v0.22.0`을 사용한다.

## 검증

로컬 전체 1,377개 중 1,347개 통과, 환경에 따른 30개 건너뜀, 실패·오류 0개.
한국어 19개·상태 6개·도구 22개 집중 검사와 독립 검토를 수행했다.
최종 source의 원격 CI, ZIP 멤버/Git blob 일치, 공개 재다운로드 SHA256 검증은
공개 릴리스의 `verification.json` 및 `SHA256SUMS`에 별도로 기록한다.

## 알려진 경계

합성 대조군은 실제 모델의 자유형 QA 품질을 증명하지 않는다. 실제 Qwen3.5-9B
4회 관측은 영어 2건 성공·한국어 2건 실패, 공격 목표 0건·모델/통신 오류 0건이다.
한국어는 요청한 코드 대신 상태 문장을 보냈다. 한 번씩의 고정 시험은 일반 성능이나
보안 인증이 아니며 모델·프롬프트 개선은 별도 비교 대상이다. 실제 업무 볼트·DB·
메시지를 평가에 사용하지 않았다. 비용 미확인 값과 문자량 기반 추정을 구분한다.
