# v0.54.0 — 불가시 유니코드 차단, 훅 배선·설치 상태 진단, CI 정적 위생 및 릴리스 주장 자동 검증

공개 v0.53.2(커밋 `fcb9a5dd368bdd74ecfa21f6e308dd3b813912f2`)를 바탕으로 외부 오픈소스 연구 두 건에서 선별한 네 묶음의 보안·운영·검증 개선을 Python 표준 라이브러리만으로 구현해 공개한다. [`affaan-m/ECC`](https://github.com/affaan-m/ECC) (`v2.2.3`, 커밋 `ccd8da1a72`, MIT)에서 불가시 유니코드 밀수 방어·읽기 전용 훅 배선 감사·설치 상태 소유권 모델·정적 CI 위생 개념을, [`connectome-cognition-benchmark v1.1.0`](https://doi.org/10.5281/zenodo.24361690)([`ai3inc/connectome-cognition-benchmark`](https://github.com/ai3inc/connectome-cognition-benchmark), 커밋 `9c5d863256fdc20c341b94b874e62921e92f22c1`, MIT)에서 출처 고정 수치 원장과 선언형 주장 검증 패턴을 참고하되, 모든 코드는 `agentic-vault`의 무의존성·로컬 경계에 맞춰 새로 작성했다(신경과학 파이프라인, Node/Rust 런타임, 범용 스킬 팩은 도입하지 않는다).

## 변경

1. **`SessionStart` 및 `vault_doctor`의 불가시 유니코드 밀수·양방향 제어 차단** ([hooks/session_start.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/hooks/session_start.py), [skills/agentic-vault/scripts/vault_doctor.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/skills/agentic-vault/scripts/vault_doctor.py), [tests/test_session_header_lines.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_session_header_lines.py)).
   `_strip_invisible_smuggling`을 비밀 마스킹과 가짜 머리글 줄 무력화 앞단에 넣어, Unicode Tag 블록(`U+E0000`–`U+E007F`), Variation Selectors Supplement(`U+E0100`–`U+E01EF`), 양방향 제어 문자(`U+202A`–`U+202E`, `U+2066`–`U+2069`), 몽골 모음 구분자(`U+180E`), 한글 채움자(`U+115F`–`U+1160`), 불가시 수학 연산자(`U+2061`–`U+2064`)를 주입 전에 제거한다. 이로써 불가시 문자로 위장한 비밀값이나 가짜 머리글 줄도 노출돼 함께 차단된다. 정상 노트·한글·일반 이모지(`⚠️`, `✅`)는 바이트 단위로 유지되며, `vault_doctor.py`도 같은 순서를 적용해 추정 글자 수를 일치시킨다.
2. **읽기 전용·무누출 훅 배선 대상 감사 (`--hook-wiring`)** ([skills/agentic-vault/scripts/vault_hook_wiring.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/skills/agentic-vault/scripts/vault_hook_wiring.py), [skills/agentic-vault/scripts/vault_doctor.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/skills/agentic-vault/scripts/vault_doctor.py), [tests/test_vault_hook_wiring.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_vault_hook_wiring.py)).
   `vault_doctor.py --hook-wiring` 선택 옵션을 추가했다. `.claude/settings.json`·`.claude/settings.local.json`의 훅 명령(`command`·`args`)과 `00-meta/scripts/git-hooks/`가 가리키는 스크립트 파일의 실존 여부만 읽기 전용·비차단으로 감사하며, 원시 훅 명령·환경 변수·예외 문구는 출력하지 않고 누락 경로와 건너뛴 명령 수(`commands_skipped`)만 보고한다.
3. **결정론적 설치 상태 원장과 소유권 보호 안전 제거 (`vault_install_state.py` · `--install-state`)** ([skills/agentic-vault/scripts/vault_install_state.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/skills/agentic-vault/scripts/vault_install_state.py), [tests/test_vault_install_state.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_vault_install_state.py)).
   `00-meta/.vault-install-state.json`(`agentic-vault/install-state/v1`)에 엔진 스탬프가 있는 관리 파일(`managed`)과 사용자 소유 파일(`user_owned`: `CLAUDE.md`, `00-meta/vault-config.json`, `00-meta/lessons.md`, 스탬프 없는 `AGENTS.md` 등)의 SHA-256을 기록(`record`)하고, 드리프트 진단(`status`, `vault_doctor.py --install-state`) 및 안전 제거(`uninstall`, 기본 dry-run, `--apply` 지정 시 기록 해시와 일치하는 미수정 `managed` 파일만 제거하고 사용자 파일·사용자 수정본은 항상 보존, 심볼릭 링크·정션·볼트 외부 경로는 fail-closed 거부)를 제공한다.
4. **저장소 CI 정적 보안·이식성 회귀 시험 4종** ([tests/test_repo_hygiene.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_repo_hygiene.py), [tests/test_supply_chain.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_supply_chain.py)).
   추적 텍스트 파일 전체의 불가시 유니코드 밀수 검사, 배포·실행 표면의 개인 로컬 경로 유출 검사, Codex·Antigravity 스킬/매니페스트의 Claude 전용 치환 토큰 누출 검사, GitHub Actions 워크플로의 `pull_request_target`·`workflow_run` 비신뢰 PR 체크아웃 차단 검사를 추가했다.
5. **출처 고정 릴리스 수치 원장 및 선언형 주장 검증기 (`scripts/verify_release_claims.py`)** ([scripts/verify_release_claims.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/scripts/verify_release_claims.py), [tests/test_verify_release_claims.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/tests/test_verify_release_claims.py)).

## 기본 결과 변경

- 판 메타데이터: 매니페스트 버전·설치 태그·healthcheck 스탬프(`engine=0.54.0`, 2행)와 `ENGINE_VERSION`이 `0.54.0`으로 이동한다.
- `hooks/session_start.py` 및 `vault_doctor.py`: 위험 불가시 밀수·양방향 제어 문자(`U+E0000`–`U+E007F`, `U+E0100`–`U+E01EF`, `U+202A`–`U+202E`, `U+2066`–`U+2069`, `U+180E`, `U+115F`–`U+1160`, `U+2061`–`U+2064`)가 포함된 노트에서만 해당 코드포인트가 제거된 뒤 비밀 마스킹과 머리글 무력화가 적용된다. 정상 노트의 출력은 v0.53.2와 바이트 단위로 같다.
- `vault_doctor.py`: 선택 플래그 `--hook-wiring`·`--install-state`가 추가된다. 플래그를 주지 않은 기본 출력과 종료 코드는 v0.53.2와 같다.
- `vault_install_state.py`·`scripts/verify_release_claims.py`: 새로 추가된 선택형 도구이며 기존 명령·훅·`vault_healthcheck.py` 판정을 바꾸지 않는다.

## 하위호환·업그레이드

현재 설치 ref는 `v0.54.0`이다.

기존 볼트 설정 키는 추가하거나 마이그레이션하지 않는다. 공개 준비나 GitHub Release 게시는 활성 호스트 설치나 기존 볼트 사본을 자동으로 갱신하지 않는다. 볼트에 복사된 healthcheck는 설치 호스트에서 플러그인을 갱신한 뒤 `/vault-upgrade`(Codex는 `upgrade`)로 별도 갱신한다.

인증서가 묶는 일곱 파일(`vault_lint_extensions.py`·`vault_warning_policy.py`·`vault_provenance.py`·`vault_egress.py`·`vault_ssot.py`·`jev_client.py`·`vault_paths.py`)은 v0.46.0부터 v0.54.0까지 바이트 단위로 같아, 실제 설치 바이트가 같은 경우 기존 경고 승격 인증서가 그대로 유효하다. `checker_sha256`는 `09642e7aa77d0b812f5afa646b491fe2d79d44104e399bea4a3001a6f2f1279d` 그대로다. v0.45.1 이하와 오갈 때는 [v0.46.0 업그레이드 안내](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/docs/releases/v0.46.0.md#하위호환업그레이드)를 따른다. healthcheck만 `engine=0.54.0`로 이동하며 기존 규칙·어댑터 스탬프는 유지한다.

## 검증

요구 관문은 [v0.54.0 검증 계약](https://github.com/Technoetic/agentic-vault/blob/v0.54.0/docs/verification/v0.54.0.md)에 적었다. 최종 커밋의 병렬 시험 수·종료 코드, 150자 Windows `TEMP`(`LongPathsEnabled=0`) 전체 시험과 Hypothesis 상태기 시험, 후보 분기·태그·`master` CI(총 36개 작업 모두 게시 전 완료), `scripts/verify_release_claims.py` 10/10 통과, 독립 검토, ZIP L1/L2 재빌드, 격리된 Codex·Antigravity 설치 확인과 인증서 재생 결과는 GitHub Release의 `verification.json`에 기록한다.

회귀 시험에는 `tests/test_session_header_lines.py`의 불가시 밀수 제거·비밀/머리글 연동·doctor 일치 시험, `tests/test_vault_hook_wiring.py`, `tests/test_vault_install_state.py`, `tests/test_repo_hygiene.py`, `tests/test_verify_release_claims.py`, `tests/test_supply_chain.py`의 워크플로 보안 시험, 그리고 `tests/test_release_metadata.py`의 `V0540ReleaseMetadataTests`를 추가했다.

## 알려진 경계

- `_strip_invisible_smuggling`은 명시한 불가시 밀수·양방향 제어 코드포인트만 제거하며, 시각적 유사 문자(호모글리프)나 일반 텍스트 기반 프롬프트 주입 자체를 막는 보안 샌드박스가 아니다.
- `vault_hook_wiring.py`는 정적 경로 실존 여부만 점검하며 훅을 실행하거나 셸 환경 전체를 평가하지 않는다. 해석할 수 없는 변수는 추측하지 않고 `commands_skipped`로 집계한다.
- `vault_install_state.py uninstall`은 `00-meta/.vault-install-state.json`에 기록된 미수정 `managed` 파일만 제거한다. 기록이 없거나 사용자가 수정한 파일, 사용자 소유 파일(`CLAUDE.md`, `00-meta/vault-config.json`, 스탬프 없는 `AGENTS.md`, 일반 노트)은 건드리지 않으며 호스트 전역 플러그인 캐시도 제거하지 않는다.
- Antigravity CLI 생성 패키지는 `agy plugin validate --strict`와 격리된 설치·바이트 대조로 검증하며, 실제 `agy` 대화 세션은 에이전트가 감싸 실행하지 않는다.
