# v0.39.1 — timeout assertion portability patch

v0.39.1 supersedes the **unpublished v0.39.0** candidate with a **test-only**
correction. Its original stage-intervention and fresh Korean observation features
remain available. No evaluator runtime behavior, transport boundary, failure
accounting, installed default, dependency or resource-list requirement changes.
No actual-model inference or new model-performance result is asserted here.

## Candidate failure and correction

Candidate source `0b91cb43a4ea4df1ed857b34e52ab8ca4c2029f5` has preserved tag
CI run 41660095934. The macOS / Python 3.10 full unit job ran 2,822 tests with
81 skips and one failure: the stage transport timeout test required
`request_timeout`, but the native socket timeout correctly surfaced as
`transport_error`. This is failed candidate evidence, not a passing patch run.
No formal v0.39.0 release was published, and its tag/CI records are retained.

The shared transport has two valid timeout outcomes: a native socket failure is
reported as `transport_error`, and the outer queue deadline reports
`request_timeout`. The stage runtime already stops subsequent requests after
either outcome. The live local HTTP test accepts either valid outcome while
still checking that only one request is sent and later observations are marked
`run_stopped`. A deterministic regression checks both error paths explicitly.
The correction does not relabel runtime errors, fabricate durations or retry
failed requests. Local HTTP contract services remain distinct from model inference.

## Retained feature scope

- [Stage evaluation](../memory-stage-evaluation.md) uses original ASCII/Korean
  synthetic fixtures and real stored/consumer contexts to compare writing,
  management and retrieval interventions. Clean-task preservation, poison
  exposure, bad-plan adoption, errors and incomplete pairs remain separate.
  Deterministic interventions are not model-generated memory or strict
  four-phase selective-repair evidence.
- [Fresh Korean observations](../model-korean-memory.md) give both retrieval arms
  independent requests and reuse the strict answer grader. Source-bound replay
  checks labels, evidence, sample order, configuration and local code closure;
  hashes do not authenticate inference, origin or truth. Identical prompts do
  not establish annotation efficacy.

Both default evaluator CLI commands remain offline scripted controls within the
existing CI matrix. Actual inference requires an explicit model, literal-loopback
endpoint and network opt-in. This is not an official Inspect SDK integration or
a copied NoMIRACL dataset. Scripted controls are not actual-model performance
evidence; the [candidate feature record](v0.39.0.md) remains historical.
