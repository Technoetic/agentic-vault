# agentic-vault v0.14.0

날짜: 2026-09-20

볼트에서 찾은 근거에 대해 선택형 의미 질문을 Jev에 맡길 수 있다. `/vault-judge` 또는
Codex `$agentic-vault:agentic-vault judge <질문>`으로 사용한다. 적합한 자연어 질문도
공유 스킬의 지침에 따라 같은 절차로 연결한다.

## 변경

- 요구 충족·주장 지지·관련성·의미 중복·감정·분류·의미상 yes/no의 7개 과제.
- 질문마다 사용자 정의 선택지·판정 기준·판단 보류 선택지를 지정한다.
- 원문 발췌 바인딩, 출처 행 번호와 해시, 전후 원문/설정 변경 검사.
- `prepare`는 오프라인, `run --allow-network`는 승인된 발췌만 1회 전송한다.
- 선택 결과·확률·확신도와 `reviewed`, `needs_review`, `unverified` 상태를 반환한다.
- 표준 라이브러리만 사용하며 API 키는 프로세스 환경변수 `TYPESAFE_API_KEY`에서 읽는다.

## 하위호환·업그레이드

기존 검색·검사·권한·노트 쓰기와 독립된 선택 기능이다. SDK 설치, 볼트 설정 변경,
시작 시 네트워크 호출이 없다. 기존 `gates`의 실행 집행 범위는 바뀌지 않는다.
플러그인 갱신 후 Claude Code를 재시작하거나 Codex 새 대화를 시작한다.
기존 프로세스에서 환경변수 키를 새로 설정했다면 앱 프로세스도 재시작해야 한다.
NS 등 자체 엔진을 가진 볼트의 검사기·설정을 자동 덮어쓰지 않는다.

## 검증과 경계

[검증 기록](../verification/v0.14.0.md)과 [사용 안내](../jev-judgments.md)를 참고한다.
자연어 분기는 호스트 스킬의 실행 지침이며 모든 대화를 가로채는 강제 훅이 아니다.
Jev 출력은 보조 판단이며 확신도는 실제 정답률 보증이 아니다. 수치 계산·파일 존재·해시·
날짜 비교·권한 결정은 기존 코드와 규칙으로 처리한다. 보류·실패를 부정이나 PASS로 바꾸지 않는다.
외부 전송 승인은 선택한 자료와 목적에 대해 필요하며, 이미 받은 승인을 반복 요청하지 않는다.
