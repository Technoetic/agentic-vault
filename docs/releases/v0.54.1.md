# v0.54.1 — 불가시 유니코드 7종 보강, UTF-8 BOM 정리·차단, 백업 POSIX 디렉터리 fsync 및 CI actionlint

공개 v0.54.0(커밋 `2b35dc0635edb453077aecebac5717e05afe25c8`)을 바탕으로 11차 연구 조사에서 확인된 즉시 적용 가능한 보안·위생·내구성·CI 거버넌스 패치 네 건을 Python 표준 라이브러리만으로 구현해 공개한다. 새 런타임 의존성은 없으며 경고 승격 인증서가 묶는 일곱 파일은 바이트 단위로 유지한다. [Trojan Source](https://www.usenix.org/conference/usenixsecurity23/presentation/boucher)(Boucher & Anderson, USENIX Security 2023), [Unicode UTS #39](https://www.unicode.org/reports/tr39/)(Unicode 18.0.0), [Bad Characters](https://arxiv.org/abs/2106.09898)(Boucher et al., IEEE S&P 2022), [Pillai et al. (OSDI '14)](https://www.usenix.org/conference/osdi14/technical-sessions/presentation/pillai), 그리고 [`rhysd/actionlint`](https://github.com/rhysd/actionlint)(`v1.7.12`, MIT)를 근거로 삼았다.

## 변경

1. **`SessionStart`·`vault_doctor`·저장소 정적 위생 검사의 `Default_Ignorable` 불가시 유니코드 7종 보강** ([hooks/session_start.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/hooks/session_start.py), [tests/test_session_header_lines.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/test_session_header_lines.py), [tests/test_repo_hygiene.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/test_repo_hygiene.py), [SECURITY.md](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/SECURITY.md)).
   `_strip_invisible_smuggling`과 저장소 정적 위생 검사에 소프트 하이픈(`U+00AD`), 결합 자소 접합자(`U+034F`, 일반 범주 `Mn`), 아랍어 문자 표지(`U+061C`), 방향성 표지(`U+200E`·`U+200F`), 한글 채움자(`U+3164`·`U+FFA0`) 7종을 추가했다. `SessionStart`(`startup`·`compact`·`--host antigravity`)와 `vault_doctor`가 비밀 마스킹 및 가짜 머리글 무력화 앞단에서 이 7종을 제거하므로 `U+034F`로 위장한 GitHub 토큰과 `U+00AD`/`U+200E`/`U+3164`로 가린 가짜 섹션 머리글도 함께 차단된다. 정상 한글·ASCII·이모지(`⚠️`, `✅`)와 v0.52.1 머리글 단독 함수 단위 계약은 그대로 유지한다.
2. **추적 텍스트 파일 5개의 선두 UTF-8 BOM 제거 및 CI BOM 차단** ([docs/knowledge-evolution.md](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/docs/knowledge-evolution.md), [docs/recoverable-bundles.md](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/docs/recoverable-bundles.md), [tests/fixtures/knowledge_evolution/history.json](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/fixtures/knowledge_evolution/history.json), [tests/test_repo_hygiene.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/test_repo_hygiene.py)).
   문서 2건·JSON fixture 1건과 `antigravity/` 생성 사본 2건의 선두 3바이트 UTF-8 BOM(`EF BB BF`)을 제거하고, `tests/test_repo_hygiene.py`가 추적 텍스트 파일의 선두 UTF-8 BOM 재유입을 차단하도록 보강했다.
3. **`backup_vault.py`의 POSIX 부모 디렉터리 `fsync` 내구성 보강** ([skills/agentic-vault/scripts/backup_vault.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/skills/agentic-vault/scripts/backup_vault.py), [tests/test_backup_vault.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/test_backup_vault.py)).
   `backup_vault.py`에 `_sync_dir` 도우미를 추가해 POSIX 환경(`os.name != "nt"`)에서 `manifest.json` 기록 뒤 `stage` 디렉터리, `os.replace` 게시 뒤 `snapshots` 부모 디렉터리, 그리고 `restore_snapshot` 완료 뒤 `destination`과 `destination.parent` 디렉터리에 `O_RDONLY | O_DIRECTORY | O_NOFOLLOW`로 `os.fsync`를 호출한다(`EINVAL`/`ENOTSUP`/`EOPNOTSUPP`는 비지원 파일시스템으로 허용하고 `EIO` 등 실제 I/O 오류는 전파한다). Windows에서는 무동작으로 안전하게 통과한다.
4. **CI 경고 전용 SHA-256 고정 `actionlint` (`v1.7.12`, MIT) 및 저장소 Dependabot 보안 업데이트** ([.github/workflows/tests.yml](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/.github/workflows/tests.yml), [tests/test_supply_chain.py](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/tests/test_supply_chain.py), [docs/release-integrity.md](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/docs/release-integrity.md)).

5. **판 표면 및 생성 `antigravity/` 패키지 정렬.**
   세 매니페스트, `antigravity/` 생성 패키지, `vault_healthcheck.py`(`engine=0.54.1`), `README.md`, `SECURITY.md`, `docs/README.md`, `docs/antigravity.md`, `docs/codex.md`, `docs/release-integrity.md`를 `0.54.1`로 정렬했다.

## 하위호환·업그레이드

현재 설치 ref는 `v0.54.1`이다.

기존 볼트 설정 키는 추가하거나 마이그레이션하지 않는다. 공개 준비나 GitHub Release 게시는 활성 호스트 설치나 기존 볼트 사본을 자동으로 갱신하지 않는다. 볼트에 복사된 healthcheck는 설치 호스트에서 플러그인을 갱신한 뒤 `/vault-upgrade`(Codex는 `upgrade`)로 별도 갱신한다.

인증서가 묶는 일곱 파일(`vault_lint_extensions.py`·`vault_warning_policy.py`·`vault_provenance.py`·`vault_egress.py`·`vault_ssot.py`·`jev_client.py`·`vault_paths.py`)은 v0.46.0부터 v0.54.1까지 바이트 단위로 같아, 실제 설치 바이트가 같은 경우 기존 경고 승격 인증서가 그대로 유효하다. `checker_sha256`는 `09642e7aa77d0b812f5afa646b491fe2d79d44104e399bea4a3001a6f2f1279d` 그대로다. v0.45.1 이하와 오갈 때는 [v0.46.0 업그레이드 안내](https://github.com/Technoetic/agentic-vault/blob/v0.54.1/docs/releases/v0.46.0.md#하위호환업그레이드)를 따른다. healthcheck만 `engine=0.54.1`로 이동하며 기존 규칙·어댑터 스탬프는 유지한다.

## 알려진 경계

- `_strip_invisible_smuggling`은 명시한 불가시 밀수·양방향 제어·`Default_Ignorable` 코드포인트만 제거하며, 시각 호모글리프(키릴·그리스 유사 문자 등)나 일반 텍스트 프롬프트 주입을 막는 보안 샌드박스가 아니다.
- `jev_client.py` 직접 CLI 호출 경로는 경고 승격 인증서(`checker_sha256`) 호환성을 유지하기 위해 이번 패치에서 수정하지 않았다. `SessionStart` 주입 경로는 `U+034F`를 제거한 뒤 마스킹하지만, `jev_client.py` 직접 호출의 `U+034F`(`Mn`) 보강은 다음 계획된 인증서 전환 릴리스로 남긴다.
- `backup_vault.py`의 `_sync_dir`는 POSIX 파일시스템에서만 동작하며, Windows는 디렉터리 `O_RDONLY`+`fsync`를 지원하지 않는다. 또한 체크섬 검증 복사 방식이므로 작업 중인 볼트의 파일시스템 수준 원자 스냅숏을 대체하지 않는다.
- `secret_scanning_validity_checks`는 저장소 API PATCH 응답 뒤 재조회에서도 `disabled`로 유지돼 현 저장소 등급에서는 활성화되지 않음을 기록한다.
- Antigravity CLI 생성 패키지는 `agy plugin validate --strict`와 격리된 설치·바이트 대조로 검증하며, 실제 `agy` 대화 세션은 에이전트가 감싸 실행하지 않는다.
